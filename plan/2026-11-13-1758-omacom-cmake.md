# Plan: build the six omacom apps with CMake

Approved decisions (from the spec): CMake replaces qmake in all six packages;
`pkg-config` is added to hype (monologue and signed have it) and
`libjpeg_turbo` to monologue's `buildInputs`; the hand-written
`installPhase` stays (no upstream `install()` rules; binary is in the build
dir under the same name; `pkgbuild/` files still exist); versions and hashes
come from each package's `nix-update`; hype's fetch is named
`hype-${finalAttrs.version}` so upstream's CMakeLists reads the version from
the directory name; tests stay off; omacalc keeps its own desktop entry;
qmake-describing comments are corrected.

## Steps

1. Bump versions first (the old tags have no CMakeLists): from the repo root,
   `nix-update --flake <app>` for hype, monologue, omacalc, omacut, omawrite
   and signed. It needs no build.
   → verify: `git diff` shows only `version` and `hash` in the six files.
2. `pkgs/apps/{hype,monologue,omacalc,omacut,omawrite,signed}.nix`, in each
   `nativeBuildInputs` (lines ~22-30): replace `qt6.qmake` with `cmake`, and
   add `cmake` to the function arguments. hype only: add `pkg-config`
   (argument and `nativeBuildInputs`); monologue and signed already have it,
   so do not add it twice (a duplicate formal is a parse error). monologue
   only: add `libjpeg_turbo` (argument and `buildInputs`). Correct comments
   that describe qmake (`QT += ... in <app>.pro`, "bin/build is qmake +
   make"), and omacalc's comment (~line 39) that the repo ships no
   `pkgbuild/`: it now does, and the package keeps its own desktop entry.
   → verify: `nix eval --raw .#<app>.drvPath` for all six.
   Traps: an editor hook may reformat `.nix` with nixpkgs-fmt; run `nix fmt`
   and read `git diff --stat` (CLAUDE.md §5).
3. `pkgs/apps/hype.nix`, its `fetchFromGitHub` (~line 19): add
   `name = "hype-${finalAttrs.version}";` with a one-line comment: upstream's
   CMakeLists reads the version from a source dir named `hype-<version>`.
   → verify: `strings result/bin/.hype-wrapped | grep -Fx 0.7.1` after a
   build; with the line removed, rebuild and record what it carries instead
   (expected `dev`) (§1).
4. Build all six at the package tier's gate (§6): `nix build .#<app>`.
5. Run every check `generated-checks.sh` prints, and `checks.session`, by
   tier; `nix run .#update` afterwards changes none of the six.

## Tests

- Six package builds; the hype version break proof; `checks.session`;
  the full local tier; statix, deadnix, `nix fmt -- --ci`.

## Rollback

Revert the commit: each package returns to qmake at its old version and hash.
