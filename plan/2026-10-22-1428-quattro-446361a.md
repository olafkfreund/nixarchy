# Plan: edge on Omarchy quattro 446361a

## Approved decisions

- Pin edge to upstream quattro `446361a5f75bc835fe85da7a499b82351e6eb596`.
- Drop our `timeout 3` on `omarchy-menu-keybindings`' Lua scan: upstream
  bounds it now (`timeout 10` plus a `debug.sethook` limit). Retarget our
  cache-key bump from `v17` to upstream's `v19`.
- Follow upstream's NetworkManager connectivity check as a native NixOS
  setting at `mkDefault`, not as the shipped `conf.d` file, which would
  override a user's own setting (§14).
- Classify `NetworkManager/conf.d/omarchy-connectivity.conf` as `native` in
  `data/etc-overlay.nix`.
- A coexistence fixture proves a user's own connectivity setting wins.
- **The release note is derived, not hand-written.** `release-notes.sh`
  section 2 quotes every changed `= lib.mkDefault` line under `modules/`, with
  only the leaf of a nested attrset. So the setting is written as full dotted
  paths, one per line. The derived note then reads
  `networkmanager.settings.connectivity.uri = lib.mkDefault "http://ping.omacom.io/…"`,
  which says what changed without a hand-kept note (spec step 6, refined).
