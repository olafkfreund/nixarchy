# Plan: the nightly review watches every package the daily bump updates

Approved decisions, carried from the spec:

- `pkgs/review.sh` watches owe and aether as well. Both have the shape its
  probe reads: a `version = "x"` line at the top, and releases tagged `vX`.
- `tests/review-pins.nix` keeps its independent hardcoded list, adds the two
  names, and gains a comparison: every `pkgs/apps/*.nix` containing
  `updateScript` (the attribute `.#update` selects on) must be in column 2 of
  `review.sh --list-pins`. It is read from source with grep, not by
  evaluating the flake.
- No `cut | grep -q` pipes in the check (tests/AGENTS.md, SIGPIPE under
  pipefail).

Two files and two editing steps, so the lead implements it.

## Steps

1. **`pkgs/review.sh:114-123`, the `pins` heredoc.** After the `omawrite`
   row, add two rows (tab-separated, like the others):
   `owe	pkgs/apps/owe.nix	omacom/owe` and
   `aether	pkgs/apps/aether.nix	omacom/aether`.
   → verify: `bash pkgs/review.sh --list-pins` prints 8 lines, and the owe and
   aether lines end in `0.2.11` and `4.32.0`.
   Traps: the heredoc is `<<'EOF'` with literal tabs. Check with `cat -A`
   that the separators are `^I`.

2. **`tests/review-pins.nix`.**
   - `expected` (lines 18-25): add `"owe"` and `"aether"` after `"omawrite"`.
   - After the per-name `for name in …; do … done` loop, and before
     `got=$(wc -l < pins.txt)`, insert:
     ```sh
     # Every app the daily bump updates (.#update selects on updateScript)
     # must be one the review watches; read from source, not from review.sh.
     watched=$(cut -f2 pins.txt)
     for f in pkgs/apps/*.nix; do
       grep -q updateScript "$f" || continue
       grep -qxF "$f" <<<"$watched" || {
         echo "review: $f has an updateScript (the daily bump updates it) but review.sh does not watch it" >&2
         fail=1
       }
     done
     ```
     Each `grep -q` reads a file or a here-string, not a pipe.
   → verify: `nix fmt -- --ci` (a `''…''` Nix string: no heredoc, since
   `<<<` is a here-string; check that `git diff --stat` stays small, per
   §5's reindent trap).

3. **Build and break (§1), cheap tier, under the lock.**
   - `nix build .#checks.x86_64-linux.review-pins -L` → green.
   - Break A: delete the `owe` row from review.sh (`git diff` to confirm),
     `git add -A`, build → red, naming owe ("no longer in the pin list" and
     the comparison line).
   - Break B: also delete `"owe"` from `expected` (`git diff` to confirm),
     `git add -A`, build → red from the comparison alone:
     `pkgs/apps/owe.nix has an updateScript … but review.sh does not watch it`.
   - Restore with `git checkout HEAD -- pkgs/review.sh tests/review-pins.nix`
     **after** committing steps 1-2 (§5: checkout restores HEAD only once HEAD
     holds the fix), `git add -A`, build → green, and `git status` clean.

4. **Commit** steps 1-2 (before the breaks) with subject "The nightly
   review watches owe and aether, and its pin check fails on any app the
   daily bump updates that the review does not watch (#1363)". Then the PR
   with step 3's three outputs and `Closes #1363`.
