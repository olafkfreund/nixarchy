# Plan: Keep Nixarchy user units on the current generation

NixOS already wires the user services through `wantedBy`. First-run must not `enable` them and create links to one Nix store generation. It may `start` an installed unit needed immediately. An enable-gated activation removes only the matching generated links left by prior first-runs, for every evaluated normal user's configured home; a failed removal warns but cannot fail a switch. Verification fails for missing or stale-shadowed Nixarchy units, while preserving intentional user overrides and #1101's separate Bluetooth checks. No arbitrary running process is killed.

Implementation begins **only after #1101 merges**: fetch and rebase this branch onto `origin/main`, inspect the diff and status, then generalise and replace #1101's `cleanup-bt-agent.sh` and its activation. Keep its temporary pairing behavior, retired permanent service, and Bluetooth verification. The current line references below may shift on rebase; locate by the named code before editing. Each implementation commit names its plan step; any deviation is recorded in this file in that same commit.

## Rollback
