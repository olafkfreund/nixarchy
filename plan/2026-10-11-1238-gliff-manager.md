# Plan: Gliff-Manager ships as a default plugin, from a NixOS-ready fork

This file is meant to be implementable on its own, without the intent or the
spec.

## Decisions carried from the approved spec

- **Fork.** A public GitHub fork of `28allday/Gliff-Manager` (MIT, base commit
  `b39ea9b`), named `olafkfreund/nixarchy-gliff-manager`, default branch
  `main`. The template is `olafkfreund/nixarchy-podman`.
- **Identity.** The id becomes `nixarchy.gliff-manager` and the version
  `0.1.0-nixarchy.1`. The author names both olafkfreund (the port) and Gavin
  Nugent (upstream). `LICENSE` is kept word for word.
- **What the fork fixes.**
  - The version, local and remote, comes from `gliff --version` and
    `gliff-server --version`.
  - `channel=` is the `ID` from `/etc/os-release`.
  - Client processes are found with
    `pgrep -u "$(id -u)" -x 'gliff|\.gliff-wrapped'`.
  - The Hyprland owner is the first pid from
    `pgrep -x 'Hyprland|\.Hyprland-wrapp'`, read with `ps -o user= -p`.
  - The install fix opens a terminal that explains how to get gliff, and runs
    no package manager.
  - `fix-session` is not offered when `channel` is `nixos`.
  - The `Panel.qml` banner gives no package-manager hint.
  - No `pacman` or `yay` on any non-comment line.
- **The fork's flake.**
  - `packages.default`: a `runCommand` with plain copies of the four plugin
    files.
  - `homeManagerModules.default`: steps aside, with a warning, when nixarchy
    is on.
  - One `checks.default`, which includes the behaviour test (real processes
    named `.Hyprland-wrapp` and `.gliff-wrapped`; stubs only for `gliff`,
    `gliff-server` and `ssh`; never asserts `.channel`).
  - Also `devShells.default` and `formatter`.
- **The fork's workflows.** `ci.yml`, `pages.yml` and a read-only weekly
  `upstream.yml`.
- **The fork's docs.** README, `AGENTS.md` with `CLAUDE.md` linked to it, a
  one-page `docs/` site, and an `UPSTREAM` file.
- **Release.** Tag `v0.1.0-nixarchy.1`, with a GitHub release. nixarchy pins
  that tag's commit sha.
- **nixarchy.**
  - A flake input with `nixpkgs.follows`, re-exported as a package.
  - `defaultPluginSet.gliff-manager`, gated on `preinstalls` and not
    `preinstallsExclude ∋ "gliff"`, with no `packages`, placement `right`, and
    `defaultPlugins` default `gliff-manager = true`.
  - Menu row `setup.remote.gliff-manager` runs `nixarchy-plugin`, with a
    `--enabled` `when`.
  - Counts: sixteen default plugins, twelve always on, four that follow their
    feature.
- **Process.**
  - A `coder` agent writes code steps; the session commits, builds and runs
    the proofs.
  - The fork's PR and nixarchy's PR are each reviewed by a fresh Opus agent
    and by Codex (`codex exec -s read-only`), given this plan and the diff.
  - No pull request to 28allday (§11).

### A5. `tests/behaviour.sh` (coder)

- **Setup:** `set -eu`, and `HOME`, `XDG_CONFIG_HOME` and `XDG_CACHE_HOME` in
  a temp dir.
- **Stubs**, in a `bin/` that is first on `PATH`:
  - `gliff` prints `gliff 0.3.1`;
  - `gliff-server` prints `gliff-server 0.3.1`;
  - `ssh` skips `-o X`, `-t` and `--`, takes the target, then runs the rest:
    `exec "$@"`, with stdin passed through.
- **Real processes** under nixpkgs' names:
  - `cp "$(command -v sleep)" ./.Hyprland-wrapp; ./.Hyprland-wrapp 600 &`
  - `cp "$(command -v sleep)" ./ssh-tab` (named `ssh`, in a separate dir that
    is not on `PATH`)
  - `cp "$(command -v bash)" ./.gliff-wrapped; ./.gliff-wrapped -c
    "$tabdir/ssh me@box 600; :" --headless me@box &`
  - A `trap` kills all three on exit.
- **Assertions,** each printing the actual JSON on failure:
  - `sh $plugin/gliff-manager.sh status fast | jq -e '.local.installed and
    .local.version == "0.3.1"'`;
  - `… probe me@box | jq -e --arg u "$(id -un)" '.gliff == "0.3.1" and
    .hyprOwner == $u'`;
  - `… live | jq -e '. == [{pid: .[0].pid, target: "me@box", mode:
    "headless"}]'`.
- **Check:** passes on the fixed tree.
- **§1 break proofs** (session): revert one fix at a time, run `nix flake
  check`, see it fail, then restore with `git checkout HEAD -- <file>`.
  - **(a)** `pacman -Q gliff` at :463: the status assertion fails.
  - **(b)** `pgrep -x gliff`: the live assertion fails.
  - **(c)** `ps -C Hyprland`: `hyprOwner` is `""`.

  Capture all three outputs for the PR.
- **Traps:**
  - `pgrep -x` matches the 15-character `comm`. `.Hyprland-wrapp` is exactly
    what the kernel truncates `.Hyprland-wrapped` to, so keep the name.
  - The bash child that runs the `ssh` tab must stay alive as a child of the
    `.gliff-wrapped` pid. Use `; :` so bash forks rather than `exec`s.
  - Wait up to a second for the processes to appear before asserting.
  - Verify each break landed (`git diff`) before reading a red (§1).

## Rollback

- **nixarchy:** revert the PR. That removes the input, the default, the row
  and the docs. Machines that already enabled the widget keep a `shell.json`
  entry naming an id that no longer exists, which the shell ignores. Their
  enabled-once marker stays, which is harmless.
- **The fork:** independent of nixarchy. Archive the repository if it is
  abandoned.
- **The announcement:** edit the post with a correction; it is never deleted.
