# Plan: the pkexec probe either passes or says why it failed

## Approved decisions (self-contained)

- **One helper, `pkexec_probe(launch, label, ok_file)`,** in `tests/session.nix`,
  used by both pkexec probes: the Hyprland-dispatched one (`:510-532` on
  `main`) and the `systemd-run --user` one (`:534-550`). It runs three stages.
  1. **Agent ready for the shell running now.**
     - Read the Quickshell PID. Poll up to 120 s for
       `journalctl -b -t omarchy-shell _PID=<pid> -o cat`, captured into a
       variable, containing `omarchy polkit agent registered`.
     - If the PID changes, re-read it and keep waiting.
     - Fail at once if that PID logged
       `omarchy polkit agent is not registered`.
     - Why by PID: the shell can be relaunched mid-session, and the old
       probe's whole-boot grep can match a dead shell's line. The plugin has no
       IPC (`PolkitAgent.qml` declares no `IpcHandler`).
  2. **Launch, checked.**
     - The Hyprland probe captures `hyprctl dispatch`'s reply and fails at once
       on anything but `ok`, quoting the reply and the instance signature.
     - Both probes wrap pkexec so its output goes to `/tmp/pkexec-<label>.log`
       and its exit code to `/tmp/pkexec-<label>.rc`.
  3. **The dialog.** Wait up to 90 s for a `polkit-agent-helper@*` unit, as
     today. On timeout, print before failing:
     - the dispatch reply;
     - the pkexec log and exit code, or "absent", which means pkexec never
       ran;
     - `journalctl -b -u polkit | tail -40`;
     - `journalctl -b -t omarchy-shell | tail -40`;

     then fail with a one-line summary naming the stage.
- **The rest is unchanged:** `send_chars("omarchy\n")` and the root-owned
  `ok_file` check, with the same timeouts and no retries.
- **§1 by two staged breaks on a throwaway CI branch:**
  - the agent never registers → red at stage 1, with the diagnostics;
  - a wrong `HYPRLAND_INSTANCE_SIGNATURE` → red at stage 2, quoting
    `hyprctl`.

## Repo traps

- **Work only in `/mnt/data/vmtest/wt-1161`** (branch
  `fix/1161-pkexec-probe`, rebased on `main` `4e87e553`). Scratch trees are
  `git worktree add --detach`, never `cp -a`.
- **Never pipe into `grep -q`:** capture into a variable, then use Python
  `in` (`tests/AGENTS.md`).
- **No heredocs inside Nix strings** (§5). The existing probe writes
  `/tmp/pkexec-probe.sh` from a Python string inside the test script. That
  is fine: it is a Python heredoc in a `machine.succeed` argument, not a Nix
  heredoc. Keep that shape, or build the command inline.
- **VM runs are CI's** (§6). Locally, build only the session driver (lint and
  typecheck), in the package tier.
- **Do not `pkill` by name** (§6); the probe only reads PIDs.
- **The bus-announce hook** blocks shell commands whose text mentions
  restarting machines; avoid those words.
