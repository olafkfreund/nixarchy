# Intent: fix the second round of the 2026-10-15 review

## Problem

The second review round (Codex: `modules/apps.nix`; agy: `modules/nixos.nix`;
Claude: `modules/home.nix`) left nine confirmed defects and five plausible
ones, listed in #1276. The ones users would meet:

- Picking a curated Flathub app in the search picker never enables it. The
  check guarding that branch uses `\t` in a GNU `grep -E` pattern, which never
  matches a tab (reproduced with grep 3.12).
- `nixarchy app disable '.*'` comments out every selection, because the ID is
  never validated.
- Rewriting a selection file is `cat tmp > file`, which empties the file
  before writing it.
- A line set to `enable = false;` reads as already enabled.
- In other Wayland sessions (GNOME) Omarchy's user units start too, because
  their only gate is `WAYLAND_DISPLAY`.
- A few smaller problems: the avahi override generates a stub unit when avahi
  is off; a redundant `docker.enable = mkDefault false` ties with a profile's
  `mkDefault true`; a dead `or`; activation temp files that copy instead of
  rename and reset the mode; dry runs that leave files behind; exit statuses
  that say success after a refusal.

## Proposed outcome

Every confirmed item is fixed with a check that fails first. Every plausible
item is either reproduced and fixed, or recorded in the PR as not
reproduced, with the evidence.

## Affected users and systems

Users of the Install and Remove menus and the `nixarchy app`, `pkg` and
`search` commands. Machines with avahi off, with a Docker profile module,
or running GNOME beside Omarchy. Every Home Manager activation.

## Constraints

Mode A untouched. Cheap checks locally (§6), with VM checks left to CI. One PR,
with the work shared between Codex, agy and Claude as before.

## Open questions

None. The owner approved this on 2026-10-15.
