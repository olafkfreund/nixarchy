- Not run locally, and named in each PR: `install`.
- Each PR comments `@codex review` (memory) and carries every break's failing output (§1).

**Holes, named (§3):**

- Nothing sees a real toast: a VM has no newer release to find. The check stops at `update_pending`.
- Nothing rebuilds a machine to install a browser and read `xdg-settings` back. A human runs
  `omarchy default browser firefox` once on a real machine before C closes.
- Extension force-install is not tried in a browser.
- `omarchy-install-hermes-cli --retire-mise` or `--now`, run by hand, still deletes a marked wrapper,
  edited or not (`forget_legacy`). Nothing here reaches it: `nix-bin/omarchy-migrate` runs no
  migrations and `nix-bin/omarchy-default-agent` replaces the caller. Patching it for a by-hand run
  is not worth a patch carried at every bump.

## Rollback

Each PR is one squash-merge, reverted alone with `git revert`. No state to migrate. After reverting
C, a leftover `pending-default-*` file is inert, and the app row stays in `apps.nix`, as any Install
pick does. Reverting A's step 3 restores a stray usage line and a kept wrapper, which is the safe failure.
