## Decisions carried from the approved intent and spec

1. **The kernel parameter goes in as an inline module.**
   `tests/lib/installed-target.nix:106-112`, `etcInstrumentation`, gains a
   second entry in its `imports`:

   ```nix
   imports = [
     "''${modulesPath}/testing/test-instrumentation.nix"
     { boot.kernelParams = [ "sysrq_always_enabled" ]; }
   ];
   ```

   - Never as a body line: install-encrypted's `extraInstrumentationText`
     (`tests/lib/installed-target-cases.nix:48-51`) already sets
     `boot.kernelParams` in that same attribute set, so a second one is a
     duplicate attribute.
   - Why it works: `sysrq_on_mask()` honours `sysrq_always_enabled` whatever
     `kernel.sysrq` holds, and nixpkgs' `test-instrumentation.nix:252` sets
     `boot.consoleLogLevel = 7`, so the `pr_info` task lines reach `ttyS0`.
   - The seed reads the same binding, so the seed and the installed target
     agree by construction. `install`'s rebuild, which must build nothing,
     is the run-time proof.
2. **`tests/boot-hang-detect.nix`.** `nodes.healthy` gets
   `boot.kernelParams = [ "sysrq_always_enabled" ]`; `nodes.frozen` does not.
3. **`tests/vm-cleanup.py`** (Codex):
   1. **Pokes.** `_poke(machine, watch, abandoned, quiet=3, task_max=90)`
      sends `nmi`, then `sendkey alt-sysrq-w`, then `sendkey alt-sysrq-t`.
      - `t` is skipped when `w`'s new console lines contain `state:D`.
      - `nmi` and `w` keep the fixed `time.sleep(watch)`.
   2. **`t`'s wait.**
      - It polls `abandoned.wait(0.2)` until no new console line has arrived
        for `quiet` s, counted from the send or from the last new line, or
        until `task_max` s have passed.
      - If `abandoned` is set, it returns at once with the entries so far.
      - Its header reads
        `poke sendkey alt-sysrq-t: N console lines within S s (quiet Q s)`.
        `S` is the seconds waited, formatted with `:.0f`.
   3. **The cut.**
      - `POKE_MAX_LINES = 3000` replaces `new[:20]` (`:109`) for every poke.
      - Beyond the cap, the entry ends with
        `"\n  (" + str(len(new) - POKE_MAX_LINES) + " more console lines not shown)"`.
   4. **`_diagnose`'s budget** (`:159`).
      - `_diagnose(machine, probe_timeout, poke_watch=None, quiet=3, task_max=90)`.
      - Its budget is `30` when `poke_watch is None`, else
        `30 + 2 * poke_watch + task_max + 5`.
   5. **`wait_for_multi_user`** gains `quiet=3, task_max=90` and passes them
      to `_diagnose` at `:74`. The `except Exception` path at `:87` still
      passes no pokes.
4. **The assertions.**
   - **`boot-hang-detect` case A** passes `task_max=10` and adds
     `poke sendkey alt-sysrq-t:` to its header list (`:25-27`).
   - **Case C** keeps the list `entries = _poke(healthy, 15, threading.Event())`:
     - `entries[0]` holds `NMI received for unknown reason`;
     - `entries[1]` holds `Show Blocked State`, replacing the
       disabled-line assertion at `:45`;
     - unless `entries[1]` contains `state:D`, `entries[2]` starts with
       `poke sendkey alt-sysrq-t:` and contains `task:`.
   - **`install`.** `tests/install.nix` gains
     `target.succeed("grep -qw sysrq_always_enabled /proc/cmdline")` beside
     `:649`.
5. **`tests/AGENTS.md`** changes everywhere that describes the old pokes:
   - `:734-735`: three pokes, and `t`'s quiet wait.
   - "Reading the pokes", `:764-774`:
     - `Show Blocked State` replaces the disabled line;
