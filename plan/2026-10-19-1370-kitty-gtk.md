# Plan: a theme change reaches kitty, and survives a rebuild in GTK

Approved decisions, carried from the spec:

- **Fix 1:** a carried substitution of `omarchy-restart-terminal`'s four
  lines (`--replace-fail` each). `pgrep -x kitty` and `killall -SIGUSR1 kitty`
  become `pgrep -x '[.]?kitty(-wrapped)?'` and
  `pkill -USR1 -x '[.]?kitty(-wrapped)?'`, and the same for ghostty with
  USR2. `procps` is already in Omarchy's runtime inputs
  (`pkgs/omarchy/default.nix:241`).
- **Fix 2:** `ExecStartPost = "-<engine>/bin/hyprchroma --target=gtk --force --quiet"`
  on `modules/home.nix`'s `omarchy-theme-gnome` unit, only when
  `osConfig.programs.nixarchyThemeEngine.enable` and `.targets.gtk` (both
  `or false`).
- A cheap check for each, each proved red, then green.
- One PR. The change goes where `main` and `edge` agree, proved by a trial
  merge.
- More than three files, so the `coder` agent does steps 1-4 and the lead
  does step 5.

## Steps

1. **`pkgs/omarchy/default.nix`:** directly after the `# CARRIED (#1368)`
   block (line 499-507, ending `fi`), add:

   ```sh
   # CARRIED (#1370): nixpkgs wraps kitty (and may wrap ghostty), so the running
   # process is .kitty-wrapped, and an exact match on the bare name misses it.
   substituteInPlace $out/share/omarchy/bin/omarchy-restart-terminal \
     --replace-fail 'if pgrep -x kitty >/dev/null; then' "if pgrep -x '[.]?kitty(-wrapped)?' >/dev/null; then" \
     --replace-fail '  killall -SIGUSR1 kitty >/dev/null' "  pkill -USR1 -x '[.]?kitty(-wrapped)?' >/dev/null" \
     --replace-fail 'if pgrep -x ghostty >/dev/null; then' "if pgrep -x '[.]?ghostty(-wrapped)?' >/dev/null; then" \
     --replace-fail '  killall -SIGUSR2 ghostty' "  pkill -USR2 -x '[.]?ghostty(-wrapped)?'"
   ```

   Each argument is on one line, with no `''` and no `${` (the `''…''` Nix
   string, §5).
   → verify: `nix fmt`, then `git diff --stat`.

2. **`tests/restart-terminal-wrapped.nix`, the new check:**
   `{ pkgs, omarchy }:` → `pkgs.runCommand "nixarchy-restart-terminal-wrapped" { nativeBuildInputs = [ pkgs.procps pkgs.coreutils ]; } ''…''`,
   which:
   - copies `${pkgs.coreutils}/bin/sleep` to `./.kitty-wrapped`,
     `./.ghostty-wrapped` and `./kitten` (`comm` is the file name), and starts
     each with `1000 &`, recording the pids;
   - runs `HOME=$TMPDIR bash ${omarchy}/share/omarchy/bin/omarchy-restart-terminal`;
   - waits up to 5 s for `.kitty-wrapped` and `.ghostty-wrapped` to be gone
     (`kill -0` fails), and asserts `kitten` is still alive;
   - prints a named failure for each (`".kitty-wrapped did not get SIGUSR1"`,
     and so on), kills its own pids, and exits 1 on any failure; otherwise it
     ends with `touch "$out"`.

   Use `wait`/`kill -0` and no `grep -q` pipes (#1352).
   → verify: `nix fmt`.

3. **`tests/theme-gnome-gtk.nix`, the evaluation check:**
   `{ inputs, pkgs }:`, modelled on `tests/options.nix`'s `configWith`
   (lines 16-46: `nixosSystem` with `nixosModules.nixarchy` plus
   `home-manager.nixosModules.home-manager`, user `someone`). It takes an
   argument that is merged into the NixOS config, so the three cases are:
   (a) `{ }`, the defaults, with the engine on (the user is set);
   (b) `{ programs.nixarchyThemeEngine.targets.gtk = false; }`;
   (c) `{ programs.nixarchyThemeEngine.enable = false; }`.
   Set `programs.nixarchy.user = "someone"` as `options.nix`'s home cases do.
   Read
   `config.home-manager.users.someone.systemd.user.services.omarchy-theme-gnome.Service.ExecStartPost or [ ]`
   and assert with `pkgs.lib.assertMsg`, as `tests/bluetooth-pairing.nix`
   does:
   - (a) one element containing `hyprchroma --target=gtk`;
   - (b) and (c) empty.

   Each message names the case. End with
   `pkgs.runCommand "nixarchy-theme-gnome-gtk" { } "touch $out"`.
   → verify: `nix eval --raw .#checks.x86_64-linux.theme-gnome-gtk.drvPath`
   under the lock (evaluation only, and this is where the asserts run).

4. **`modules/home.nix`, Fix 2**, and **`flake.nix`, registration.**
   - In `home.nix`'s `let`, add `themeEngineGtk = (osConfig.programs.nixarchyThemeEngine.enable or false) && (osConfig.programs.nixarchyThemeEngine.targets.gtk or false);`
     with a one-line comment (#1370).
   - In `omarchy-theme-gnome.Service`, add
     `ExecStartPost = lib.optional themeEngineGtk "-${osConfig.programs.nixarchyThemeEngine.package}/bin/hyprchroma --target=gtk --force --quiet";`
   - In `flake.nix`, beside `appimage-extract`, add
     `restart-terminal-wrapped = import ./tests/restart-terminal-wrapped.nix { pkgs = pkgsFor.${system}; omarchy = self.packages.${system}.omarchy; };`
     and `theme-gnome-gtk = import ./tests/theme-gnome-gtk.nix { inherit inputs; pkgs = pkgsFor.${system}; };`,
     each with a one-line comment.
   → verify: `git add -A`, `nix fmt`, and evaluate both checks' `drvPath`.
   Traps: `osConfig` is `null` for a standalone Home Manager, and
   `null.programs or false` is `false` in Nix (`or` covers a missing
   attribute on null). Confirm that with `nix eval --expr`.

5. **Lead: prove and ship** (cheap tier under the lock; `.#omarchy` is
   package tier).
   - Green: `.#omarchy`, `checks.restart-terminal-wrapped`,
     `checks.theme-gnome-gtk`.
   - Red, Fix 1: build the kitty check against an unpatched Omarchy (pass
     `omarchy = <origin/main's omarchy>` via a scratch expression, or
     temporarily drop the substitution, confirm with `git diff`, and build).
     `.kitty-wrapped` must survive.
   - Red, Fix 2: drop the `ExecStartPost` line, confirm, and evaluate. Case
     (a)'s message must fire.
   - Restore with `git checkout HEAD --`, after committing (§5).
   - Edge: a `git worktree add --detach` of `origin/edge-candidate` with this
     branch merged must be **conflict-free**, and its `.#omarchy` and
     `checks.restart-terminal-wrapped` green.
   - Commit, open the PR with `Closes #1370`, and set auto-merge.
   - After deploy, on p620: a theme change recolours a running kitty without
     a restart, and after a switch `gtk-theme` reads `adw-gtk3*` without the
     owner's override. The owner checks this and drops the override.
