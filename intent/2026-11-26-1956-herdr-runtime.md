# Intent: login does not fail on a missing herdr

Approved by the owner's standing pre-approval and "close as many as possible issues" (2026-11-26).

## Problem

A fresh account logged in to `Command not found: "herdr"`. Upstream's `default/hypr/autostart.lua` starts `herdr server` at every login, and only the per-user herdr plugin installed herdr, so an account the Home Manager step had not reached (as in #1950) had none.

## Proposed outcome

The command the session starts is on the system PATH for every user.

## Affected users and systems

Every nixarchy session.

## Constraints

Mode A untouched (runtimeDeps install only under `programs.nixarchy.enable`); §2: what we ship names something, so a check says it exists.

## Open questions

None.
