## Decisions carried from the spec

- **Pin gate.** In `pkgs/omarchy/default.nix`, `isEdge = lib.hasPrefix
  "edge-" version`. Each patch that differs by pin is `if isEdge then … else …`,
  and each side is a strict `--replace-fail`. Under `main`'s v4.5.0 pin the
  stable side is byte-identical to today, so edge's `main-pin` job proves main
  is unchanged. No pin-agnostic `sed`.
- **Ownership test.** One sourced helper,
  `share/omarchy/lib/nixarchy-store-owned.sh`, defining `store_owned PATH`:
  true when `readlink -f PATH` (or of its directory when PATH does not exist)
  starts with `/nix/store/`. Every guard below uses it. Every fixture has a
  file-link and a directory-link variant (#1304, CLAUDE.md §1 "a content test
  is not an ownership test").
- **D1, Chromium stays the default.** Edge only:
  - P3, `omarchy-provision-user`: replace the whole line `env -u BROWSER
    XDG_CURRENT_DESKTOP= xdg-settings set default-web-browser
    google-chrome.desktop`. The new lines keep the `env` prefix, run `get`
    (`|| true`), and set `chromium-browser.desktop` only when `get` printed
    nothing and `~/.config/mimeapps.list` is not store-owned. The next line
    (`xdg-mime default HEY.desktop …`) gets the same ownership guard. The
    `chromium.desktop` rename loop (:1247) stays, because
    `omarchy-default-browser` and `omarchy-remove-browser` still name it.
  - P1: drop the `case` patch at :578–581 on edge (upstream lists `chromium*`).
  - P2: on edge replace `browsers=(google-chrome.desktop chromium.desktop)`
    with `browsers=(chromium-browser.desktop google-chrome.desktop)`. The
    `exec setsid uwsm-app -- "$browser_exec"` quoting patch matches both pins
    and stays outside the gate.
  - P4, `omarchy-install-service-1password` (:876–891): on edge replace the
    body of `install_browser_extension` with the existing declarative message
    (`programs.chromium.extensions`) and `return`. The bin-ledger row stays

## Rollback

The carry lives only on `edge-candidate` until an edge run promotes it. Before
promotion: delete the carry commits from `edge-candidate` (ask the owner
first; that is a force-push of a shared branch, §11), or let a later run
replace it. After promotion: revert the carry commit on `edge`; edge goes back
to `ceb30ed`'s behaviour, and p620 and razer roll back with `nixos-rebuild
switch --rollback` if they deployed it. Nothing touches `main` except the
artifacts PR.
