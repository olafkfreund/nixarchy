# Plan: Omarchy's input methods can be chosen and used on nixarchy

**Roles (owner's rule).** Codex and agy are the only coders. The Opus supervisor
supervises, runs every check, runs `nix fmt`, and commits. Neither coder can build
(no nix daemon), so "Check" in each step is run by the supervisor after the coder hands
back. Steps 1 and 11 edit no code and stay with the supervisor. No `coder` agent.

## Approved decisions

Line numbers are at `origin/main` 3c7da2c6. Four other tasks edit `modules/nixos.nix`,
so find each place by its text and treat the numbers as a hint.

1. **All machines carry five engines**, as plain list entries: `fcitx5-mozc`,
   `fcitx5-hangul`, `fcitx5-chewing`, `fcitx5-table-extra`, and Pinyin
   (`qt6Packages.fcitx5-chinese-addons`).
2. **Pinyin drops `qtwebengine`** with `-DENABLE_BROWSER=OFF`. This costs the online
   dictionary dialog, and importing a dictionary file still works. Spec measured 155 MiB
   beyond the reference closure, against 577 MiB stock. `checks.input-methods` asserts
   that `qtwebengine` stays out.
3. **Tools are in scope.** `omarchy-pkg-present` and `omarchy-pkg-add` answer truly for
   engines. Three `/usr` paths are patched. `configure.py:143` and
   `org.fcitx.Fcitx5.service:4` are not patched.
4. **A stock profile is aligned to the compositor's layout before the daemon starts.**
   A profile with any engine or a non-US group is never touched. The step is skipped
   when the user sets `i18n.inputMethod.fcitx5.settings.inputMethod`.
5. **Existing machines do not get the Shift toggle migrated.** `seed_dir` keeps their
   `config`. The release text says how to add it.
6. **Out of scope:** the installer keymap (#1619) and the fcitx5 theme path (#1624).

### The ISO gate: no merge without a number

**The PR does not merge without an `iso-budget` number in it.** The owner's approval of
the addon cost depends on it, and `iso-budget` runs only in the nightly, so a green PR
says nothing. The prediction is 6.72 GiB of 7.50, using a whole-image ratio not measured
on these addons.

**Over 7.50 GiB means Pinyin goes opt-in. The budget is not raised.** Raising it is the
owner's decision alone. Step 11 lists the edits that branch makes.

### Keeping the list easy for #1613

`i18n.inputMethod.fcitx5.addons` is a merging list, and #1613's intent defers to this
task for it. #1613 adds its own `i18n.inputMethod.fcitx5.addons = lib.mkIf … [ addon ];`
