## Steps

1. **Merge `main`, then `edge`.**

   ```bash
   cd /mnt/code/Source-home/nixarchy
   git checkout chore/1477-stable-4.5-rc2
   git fetch origin
   git merge --no-edit origin/main
   git merge --no-edit origin/edge
   ```

   **Verify:**
   - `git log --merges -2 --oneline` shows both merges, and
     `git merge-base --is-ancestor origin/edge HEAD && git merge-base
     --is-ancestor origin/main HEAD` exits 0.
   - `git diff --name-only --diff-filter=U` is empty.

   **Traps:**
   - Read each merge's exit status. Do not pipe it or `-q` it away (§5,
     the #922 lesson).
   - The trial merge of edge was clean, but `main` has since gained
     #1476 and #1478. If `flake.lock` conflicts, resolve it to **main's**
     nodes. Step 3 regenerates the `omarchy` node anyway.
   - Any other conflict: stop and report. Do not resolve it by guesswork.

2. **`data/etc-overlay.nix`: add the row** directly after the
   `"mkinitcpio.conf.d/00-omarchy-hooks.conf"` block, before
   `"mkinitcpio.conf.d/omarchy_hooks.conf"`. That is the order of
   `find | sort`, which the check diffs against.

   ```nix
     "mkinitcpio.conf.d/i2c_hid_of_module.conf" = {
       class = "na";
       reason = "MODULES+=(i2c-hid-of) for mkinitcpio, only when omarchy-hw-aarch64-qualcomm detects a Snapdragon laptop, so its internal keyboard can type the disk passphrase. nixarchy builds x86_64-linux only, and NixOS builds its initrd from boot.initrd.*; there is no MODULES list to append to.";
     };
   ```

   **Verify:** `grep -c 'i2c_hid_of_module' data/etc-overlay.nix` prints `1`.

   **Traps:** the agent hook may reformat this `.nix` file with
   `nixpkgs-fmt`. Run `nix fmt`, then check `git diff --stat` shows a
   few lines, not hundreds (§5, #897).

3. **`flake.nix` and `flake.lock`: pin the tag.**
   - `flake.nix`: the `omarchy.url` line, which is
     `"github:basecamp/omarchy/58858aecfa2a3e26c4d0a1371b369c672474fd04"`
     after the edge merge, becomes `"github:basecamp/omarchy/v4.5.0-rc2"`.
   - `flake.nix`: `omarchyVersion = "edge-20261028-58858ae";` becomes
     `omarchyVersion = "4.5.0-rc2";`. If edge has re-pinned since and
     the values differ, change whatever edge has. Both lines are
     near `flake.nix:82` and `:432`.
   - Then run `nix flake update omarchy`.

   **Verify:**
   - `jq -r '.nodes.omarchy.locked | "\(.rev) \(.narHash)"' flake.lock`
     prints exactly
     `5978d93ae7da0a325b7493501911e3f1266cadd3 sha256-spu9b69RZOHc9wPL3HemNLdleLEkLFnVxIj8IwkiMK0=`.
   - `git diff origin/main -- flake.lock` touches only the `omarchy`
     node.
   - `grep -c '58858ae' flake.nix` prints `0`.

   **Traps:**
   - `nix flake update` with no argument would bump every input. Name
     `omarchy`.
   - `pkgs/omarchy/version-label.nix` fails evaluation when
     `omarchyVersion` does not name the pin (#1407). That failure is the
     check that the two lines agree.

4. **Prove `checks.etc-overlay` fails without the row (§1).**
   1. Commit steps 2 and 3 first, as a known-good baseline, with the
      subject "Stable carries Omarchy v4.5.0-rc2, merged from edge, with
      the Snapdragon initramfs file classified (#1477)".
   2. Delete the row.
   3. Check the delete landed: `git diff` shows the 4 lines removed.
   4. Run `git add -A`.
   5. Build `checks.x86_64-linux.etc-overlay` and capture the output.
      It must fail with `+mkinitcpio.conf.d/i2c_hid_of_module.conf`.
   6. Restore with `git checkout HEAD -- data/etc-overlay.nix`, not
      `git checkout --` (§5: that restores the index, which holds the
      break).
   7. Run `git diff --cached` and `git diff`. Both must be empty.
   8. Rebuild. It must pass.

   **Traps:** cheap tier, so it may run any time, under
   `flock /mnt/data/vmtest/codex-build.lock`.

5. **Cheap checks, one at a time, under the flock:**
   - `nix fmt -- --ci`
   - `nix run nixpkgs#statix -- check .`
   - `nix run nixpkgs#deadnix -- --fail .`
   - `checks.x86_64-linux.{etc-overlay,bin-ledger,grep-q-pipefail,review-pins,options-shards}`,
     **each in its own `nix build`**, because one evaluation error
     aborts a batch (§13).

   **Verify:** every one exits 0, read without a pipe.

6. **Package tier: `packages.x86_64-linux.omarchy`.**
   - **Gate first.** `nix shell nixpkgs#gh nixpkgs#jq -c bash -c 'for a
     in install edge; do GITHUB_REPOSITORY=olafkfreund/nixarchy
     .github/scripts/vm-host-free.sh $a; done'` must print `free` twice.
     `pgrep -fc '^(nix build|nh os build|nixos-rebuild).*p620'` must be
     `0`, and the 1-minute load must be under 12.
   - **Build.** Evaluate the drvPath once, then run
     `nix build '<drv>^*'` (§5).

   **Verify:** exits 0.

   **Traps:** do not run any VM check or `options-*` case shard locally.
   CI runs those.

7. **Push, then open the PR.**
   - Push once (§6: each push restarts the install run).
   - Open the PR with the repo template. The body:
     - links intent, spec and plan;
     - links rc2's release notes;
     - pastes step 4's red and green output;
     - says the PR must be merged with `gh pr merge --merge`, never

     - says which steps the coder did;

   **Verify:**
   - `gh pr view <n> --json headRefOid` equals the pushed sha before

   - `gh pr view <n> --json mergeable` reads `MERGEABLE`.

8. **CI to green, then merge.**
   - `build` and `install check` pass on the head.
   - A failure is read, never re-run blind (§10). A `cancelled` result

   - Close #1473 with a comment pointing at the PR.
   - Confirm `main`'s own `build` and `install check` runs pass.

## Rollback

Before merge: close the PR. Nothing reaches `main`.

After merge: **do not `git revert -m 1` the merge.** Edge merges `main`
nightly, so the revert would flow into edge and undo edge's own carries
there. Fix forward in a new pull request. If stable must leave rc2, pin
`main` back to edge's last good quattro sha, which these carries were
proven on, rather than to rc1, which they no longer fit. Machines that
already moved to rc2 roll back by NixOS generation, but what 4.5 wrote
to `~/.config` stays (#1403's caveat).
