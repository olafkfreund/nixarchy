# Plan: stable moves from Omarchy v4.5.0 to v4.6.0-rc1

- **Route (a)** on `chore/1975-stable-4.6-rc1` (worktree
  `/mnt/data/vmtest/wt-1975`): merge `main`, merge `edge` for real, pin the
  tag, then the carries below. The trial tree `/mnt/data/vmtest/rc1-trial`
  holds a working version of steps 3–5 to compare against, not to copy
  blindly.
- **Pin the tag** `github:basecamp/omarchy/v4.6.0-rc1`: rev
  `745271ccd293fc2e7a233b269004a9926a5c6cb4`, narHash
  `sha256-0tGp3frcYptp7b40nb8UO+mcol3JZTm1UZYUUxC8jio=`. Never a sha.
- **One predicate** `pkgs/omarchy/is-quattro.nix`:
  `lib: version: lib.hasPrefix "edge-" version || lib.versionAtLeast version "4.6.0-rc1"`.
  Names (`isEdge`, `--edge`, `edge = "only"`) stay.

- **Every new ledger row is `edge = "only"`**; no row edge's `155c4b4` still
  needs is deleted ("this pin does not have yet" lines are informational).
- **Keep edge's history**: merge commit, `gh pr merge --merge`.
- **Do not push to `update/omarchy-v4.6.0-rc1`**; close #1972 after merge.
- **No workflow edit.** If one is needed, stop (§11).
- Implementers never stage, commit, push, build on p510, deploy or switch;
  the lead does every build, check and commit.

## Steps

1. **Merge `main`, then `edge`.** (lead)

   ```bash
   cd /mnt/data/vmtest/wt-1975
   git fetch origin
   git merge --no-edit origin/main
   git merge --no-edit origin/edge
   ```

   Verify: `git merge-base --is-ancestor origin/edge HEAD && git
   merge-base --is-ancestor origin/main HEAD`; `git diff --name-only
   --diff-filter=U` is empty.
   Traps: read each merge's exit status, never pipe it (§5, #922). A
   `flake.lock` conflict resolves to main's nodes; step 2 regenerates
   `omarchy`. Any other conflict: stop.

   the `omarchy` node.
