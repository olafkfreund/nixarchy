# Plan: edge adopts quattro ceb30ed (Files for Nautilus, Plain as the editor)

Self-contained: it carries every approved spec decision. Builds, local
checks, commits, pushes and the dispatch are the session's (Claude's), never
an agent's. Codex and the coder edit files only. They do not stage, commit,
push or build (managed rule, and `handoff`'s guard). agy is a reviewer only:
`agent-run agy` cannot reach `/mnt/data` worktrees, so step 6 goes to the
coder instead.

## Decisions (from the approved spec)

1. **Where it lands.** One carry on `edge-candidate` (now `b654130d`, the
   same as `edge`) carries the code, the pin and the pin-derived rows. The
   artifacts go to `main` on `fix/1750-quattro-ceb30ed`. The pin is quattro's
   newest commit at carry time (`ceb30ed` today), in both `flake.nix` copies
   (the input `url` and `omarchyVersion`) plus `flake.lock`. The carry is
   then dispatched with `from_candidate=true` (§8).
2. **The pin-derived flags** come from `pkgs/omarchy/default.nix`, without
   IFD:
   - `basePackages`, the split `install/omarchy-base.packages` with blank
     lines and comments dropped;
   - `hasPapers = elem "papers" basePackages`, rewritten to use it;
   - `hasFiles = elem "folio" …` and `hasPlain = elem "plain" …`;
   - `preinstallsMoonlight = hasInfix "moonlight-qt"` of
     `bin/omarchy-install-preinstalls`.

   `passthru` gains `basePackages`, `preinstallsMoonlight`,
   `fileManagerDesktop` (`"folio.desktop"` or `null`) and `editorDesktop`
   (`"plain.desktop"` or `"nvim.desktop"`).
3. **Two packages**, `pkgs/apps/folio.nix` and `pkgs/apps/plain.nix`. They
   are modelled on `owe.nix`:
   - `fetchFromGitHub omacom/<name>` at tag `v0.2.0`, with `nix-update` as
     the `updateScript`;
   - `qt6.qmake` and `wrapQtAppsHook`;
   - they install the binary, `pkgbuild/<name>.desktop`, the SVG icon and
     the MIT licence;
   - inputs: Files takes Qt base, declarative, imageformats, multimedia and
     wayland, plus `glib`, `zlib` and `libarchive`; Plain takes Qt base,
     declarative and wayland;
   - no optional dependencies (no WebEngine);
   - exported as `nixarchy-apps.folio` and `nixarchy-apps.plain`.
4. **The package.** `(if hasFiles then folio else nautilus)`, and `plain`
   when `hasPlain`. `xdg-user-dirs` is already unconditional (line 319), so
   it is not added. The editor `--replace-fail` reads
   `default-editor-install-plain.upstream.sh` when `hasPlain`, and the old
   file otherwise. Both are exact text. The desktop-ID check (line 1236)
   reads only `config/*mimeapps.list`, so it is not extended.
5. **The module** (`modules/nixos.nix`):
   - `text/plain = editorDesktop`, which means Plain on edge (decision A);
   - `inode/directory = fileManagerDesktop`, only when it is non-null;
   - both stay inside the `mkDefault` map;
   - preinstalls: `moonlight-qt` when `preinstallsMoonlight`, and `sushi`
     when `basePackages` names it;
   - a name the pin no longer installs moves from `current` to `retired` in
     the `preinstallsExclude` assertion, so old exclusions still evaluate.

   In `modules/apps.nix`, `editor:plain` joins `editor:nvim` in the
   "already ships" arm.
6. **The migrations.**
   - `1794341736`: `ported` and `edited`. Upstream's state half runs
     unchanged. The `mimeapps.list` half runs only when the file is regular
     and writable, or absent. A symlink is left alone, with a note.
   - `1794330979`: `partial` and `edited`, shaped exactly like `1794165002`.
     The `pkg-add` and `pkg-drop` lines go, the `mimeapps.list` rewrite gets
     the same symlink guard, and the `shell.json` dock block is removed. A
     user's Nautilus dock pin stays, and the ledger reason says so.
   - A fresh home (no `shell.json` before the seed) marks both done through
     the existing loop, so it gets Plain.
7. **Ledgers.** On the carry:
   - `data/omarchy-packages.nix`: `folio`, `plain`, `xdg-user-dirs` → nix,
     the stale rows removed, and hardware `skip` rows;
   - `data/user-migrations.nix`: two rows;
   - `data/apps.nix`: a `moonlight` row;
   - `data/menu-actions.nix`: `remove.gaming.moonlight` and
     `setup.default.editor.plain`;
   - `data/bin-ledger.nix`: whatever `checks.bin-ledger` names;
   - `pkgs/review.sh`: rows for `folio` and `plain`.
8. **Verification**, by §6 tier, every reachable check, including `main`'s
   pin on a scratch tree, and the §1 breaks listed in the Tests section.

## Steps

All edits are in the carry worktree,
`/mnt/data/vmtest/wt-1750-carry`, made from `origin/edge-candidate` with
`git worktree add --detach`. Commits go on top of it and are pushed to
`edge-candidate` (never a force-push).

1. **Pin** (`flake.nix` input `url` near line 82 and `omarchyVersion` near
   line 436, then `nix flake lock --update-input omarchy`).
   - Confirm quattro's head with
     `gh api repos/basecamp/omarchy/commits/quattro`. If it has moved past
     `ceb30ed`, read the extra commits for new failures before going on.
   - `omarchyVersion = "edge-<today>-<sha7>"`.
   - Verify: build `.#omarchy`, and expect exactly the editor `--replace-fail`
     failure. Anything else is new and goes in Deviations.

   Traps:
   - §5: `git add` before building;
   - §8: a carry that pins must pin both copies.

2. **Packages** (`pkgs/apps/folio.nix`, `pkgs/apps/plain.nix`; `flake.nix`
   `nixarchy-apps` near line 1267, beside `owe`; `pkgs/review.sh` pins
   table near line 125).
   - Decision 3. Hashes come from a first build with `lib.fakeHash`.
   - Verify: `nix build .#nixarchy-apps.folio .#nixarchy-apps.plain`; each
     installs `bin/<name>` and `share/applications/<name>.desktop`; and
     `<bin> --help` or `--version` exits 0 under `QT_QPA_PLATFORM=offscreen`.

   Traps:
   - `nix fmt` after editing (§5, the nixpkgs-fmt hook);
   - a new file needs `git add` before a flake sees it.

3. **The package's flags** (`pkgs/omarchy/default.nix`: the `let` near line
   130, `runtimeDeps` near 272 for nautilus, the editor `--replace-fail`
   near 1269, `passthru` near 2080; new
   `pkgs/omarchy/default-editor-install-plain.upstream.sh`, copied
   byte-exact from `ceb30ed`'s `bin/omarchy-default-editor` case block).
   - Decisions 2 and 4.
   - Verify: `.#omarchy` builds on the new pin, and
     `nix eval .#omarchy.passthru.{hasFiles,editorDesktop,fileManagerDesktop,preinstallsMoonlight}`
     gives `true`, `plain.desktop`, `folio.desktop` and `false`.

   Traps:
   - the install phase is one indented string, so keep the snippet in its
     file (pkgs/AGENTS.md);
   - `checks.install-phase-budget`;
   - an edited `substituteInPlace` needs its bin-ledger row in the same
     change.

4. **The module** (`modules/nixos.nix`: the assertion near line 970, the
   preinstalls near 1563, and `xdg.mime.defaultApplications`;
   `modules/apps.nix`: the "already ships" arm near line 2165).
   - Decision 5.
   - Verify: evaluate `vm-toplevel`'s `xdg.mime.defaultApplications` and the
     preinstall names, and `options-shards`.

   Traps:
   - §7: `mkDefault` on scalars;
   - a `mkIf false` definition still names the option (modules/AGENTS.md);
     use `optionalAttrs` for the key.

5. **The edited migrations** (`pkgs/omarchy/user-migrations.nix`, the
   `edited)` case, beside `1794165002`).
   - Decision 6. Each substitution is `--replace-fail`, on text read from
     `ceb30ed`'s scripts. A block is captured with `sed -n '/^start/,/^fi$/p'`
     and asserted to contain the line it replaces, as `1794165002` does.
   - Verify: build `.#omarchy.passthru.userMigrations`, then `bash -n` and a
     `diff` of each produced script against the upstream one.

   Traps:
   - §5: in a `''` string, `\$` is literal and only `''${` escapes;
   - the shell.json rule (#847).

6. **Ledgers** (decision 7).
   - Run `checks.omarchy-package-ledger`, `checks.user-migrations-ledger`
     and `checks.bin-ledger` first, and add exactly the rows they name.
   - Verify: those three, plus `checks.menu-actions` and
     `checks.menu-conditions`, pass.

   Traps: §4, a hand-kept list fails open, so take the names from the
   checks, not from memory.

7. **Tests** (`tests/session.nix`, `tests/coexistence/fixtures.nix`, the
   `tests/user-migrations/` fixtures).
   - `checks.session` gets probes:
     - `folio` and `plain` each map a window;
     - `xdg-mime query default` gives `folio.desktop` for `inode/directory`
       and `plain.desktop` for `text/plain`;
     - after login, `~/.local/state/omarchy/defaults/editor` is absent.
   - The coexistence fixture: the user sets both MIME keys, and their
     values win.
   - The user-migrations fixtures:
     - an existing home without state gets `nvim`;
     - a saved choice is kept;
     - a symlinked `mimeapps.list` is untouched;
     - a Nautilus handler becomes Files, and a non-Nautilus handler is kept.

   Traps:
   - tests/AGENTS.md, a pipe into `grep -q`;
   - `checks.grep-q-pipefail` after any shell edit.

8. **Local verification, commit, push, dispatch** (Claude).
   - Every check by §6 tier (Tests below), including the §1 breaks, with

   - Commit on the carry, one commit per step, and push to
     `edge-candidate`.
   - Then `gh workflow run omarchy-edge.yml -f from_candidate=true`.

9. **Artifacts PR** (`fix/1750-quattro-ceb30ed` → `main`).
   - It links the three files and names the carry commits, which steps the
     coder and Codex did, and what was not run locally, with the reason.
   - "@codex review" on it.
   - It merges with `--auto --merge --delete-branch`, as a multi-commit
     artifact branch.

## Rollback

- **The carry:** revert its commits on `edge-candidate` (a new commit, never
  a force-push), or let the next scheduled edge run start from `edge` once
  `edge-candidate` is deleted. Edge keeps `054d75e` until a run passes.
- **The artifacts:** revert the merge on `main`. No code goes to `main`
  from this branch.
- **A deployed host:** `nixos-rebuild switch --rollback`, or boot the
  previous generation.
