# Plan: Omarchy 4.5's default apps on nixarchy, and a check that catches the next one

## Approved decisions, carried over from the spec

- **Hype `v0.6.0`, Monologue `v0.3.1`, Signed `v0.3.1`.** Qt6 qmake apps
  from omacom, built the way `pkgs/apps/omawrite.nix` is. They are
  opt-in through `data/apps.nix` rows with `ours = true`,
  `preinstall = true` and `arch = "<name>"`.
- **Runtime commands go on PATH through `qtWrapperArgs`,** as
  `omacut.nix` does:
  - Hype: `ffmpeg` (ffmpeg and ffprobe) and `source-highlight`;
  - Monologue: `ffmpeg`;
  - Signed: `nss.tools` (certutil and pk12util).
- **Disktree `v0.11.0`** is the prebuilt tarball, with `autoPatchelfHook`.
  - It is a **runtime dependency of the omarchy package**, replacing
    `dua`: rc3 dropped `applications/Disk Usage.desktop`, and
    `migrations/1791345484.sh` installs Disktree unconditionally.
  - `data/arch-extras.nix` gets `disktree-bin`.
- **Titlebars `v0.3.0`** is built with nixpkgs' `mkHyprlandPlugin`,
  taken from `pkgs.hyprlandPlugins.override { hyprland = config.programs.hyprland.package; }`.
  - It is in systemPackages when `programs.nixarchy.session` is on, with
    `"/lib/omarchy-hyprland-titlebars"` in `pathsToLink`.
  - The tree rewrites `workspace-modes.lua:26` to
    `/run/current-system/sw/lib/omarchy-hyprland-titlebars/titlebars.so`.
- **`programs.nixarchy.omarchyApps.enable`** (default `false`) sets
  `apps.<n>.enable = mkDefault true` for every `ours` row with
  `preinstall = true`. That is seven: omawrite, omacalc, omacut, aether,
  hype, monologue, signed.
- **`data/omarchy-packages.nix`** classifies all 249 names in the tree's
  `install/*.packages`. Each row has exactly one of `nix`, `module` or
  `skip`.
  - **`checks.omarchy-package-ledger`** fails on a name with no row
    (unclassified), on a row for a name no list has any more (stale),
    and on a `nix` attribute that does not evaluate (unresolvable).
- **Every package** carries `passthru.updateScript` (`nix-update --flake`)
  and `meta.mainProgram`. Each app is added to **both**
  `overlays.default.nixarchy-apps` and the exported `packages.${system}`.
- **Rejected:** building Disktree from source (gpui); installing the apps
  by default; building the plugin against the flake's Hyprland input; a
  baseline-only ledger.

## Repo traps that apply throughout

- **§5:** a flake in a worktree sees only `git add`ed files. Run `nix fmt`
  after every `.nix` edit, because a hook may reformat with nixpkgs-fmt.
  No heredoc inside a `''` string.
- **§6:**
  - Package builds need load < 12 and `vm-host-free.sh` printing `free`
    for both `install` and `edge`.
  - VM checks need nothing in flight in CI. Otherwise leave them to the
    PR's CI.
  - Cheap builds run under `flock /mnt/data/vmtest/codex-build.lock`.
- **§1:** every new check is proven red, and the failing output goes in
  the PR.
- **Size limit:** the `installPhase` of `pkgs/omarchy/default.nix` is
  capped at 123,000 bytes. Keep comments there to one line, with a
  `# Why:` pointer to `pkgs/AGENTS.md`.

## Steps

1. **`pkgs/apps/hype.nix`, `monologue.nix` and `signed.nix`** (new),
   modelled on `pkgs/apps/omawrite.nix`.
   - Get the hashes with `nix-prefetch-github omacom <repo> --rev v<ver>`.
   - Install the `.desktop` and SVG from upstream's `pkgbuild/`.
   - Signed needs `pkg-config`, plus `poppler` built for Qt6 and `qpdf`:
     its `.pro` has `PKGCONFIG += poppler-qt6 libqpdf`. Find the nixpkgs
     attribute that provides `poppler-qt6.pc`; `kdePackages.poppler` is
     the likely one.
   - Hype needs `zlib` and `libwebp`, and qtsvg and qtimageformats in
     `buildInputs`, so the wrapper exports their plugins.
   - Verify: build each one (package tier), then
     `result/bin/<name> --help || true`, and check the wrapper's PATH
     with `grep -c ffmpeg result/bin/.<name>-wrapped || true`.
   - Traps: `xdg-desktop-portal` is not a build input
     (`omawrite.nix:89`).

2. **`pkgs/apps/disktree.nix`** (new): fetch
   `disktree-0.11.0-x86_64-linux.tar.gz`, sha256
   `7e75afa2283c8b4f9290d52eadbfc00d9f14c13aed2d224ccdf0f7826fcc05b2`,
   from the AUR PKGBUILD.
   - `autoPatchelfHook` with `runtimeDependencies` for wayland,
     libxkbcommon, libxcb, libGL (libglvnd), vulkan-loader and
     fontconfig. gpui `dlopen`s some of them, so autoPatchelf cannot
     see them from the ELF alone.
   - Write `disktree.desktop.in` with `@BINDIR@` → `$out/bin` and
     `@VERSION@`. Install the SVG.
   - `meta.platforms = [ "x86_64-linux" "aarch64-linux" ]`, with a hash
     for each.
   - Verify: it builds, and `ldd result/bin/disktree` shows no "not found".

3. **`pkgs/apps/omarchy-hyprland-titlebars.nix`** (new): a function of
   `{ lib, fetchFromGitHub, cmake, mkHyprlandPlugin }`, calling
   `mkHyprlandPlugin { pluginName = "omarchy-hyprland-titlebars"; ... }`.
   - CMake's install path must produce
     `$out/lib/omarchy-hyprland-titlebars/titlebars.so`. Set
     `CMAKE_INSTALL_LIBDIR` or a `postInstall` move, whichever the
     CMakeLists honours.
   - Install `LICENSE` and `LICENSE.MIT`.
   - Verify:
     `nix build --impure --expr '(builtins.getFlake (toString ./.)).nixosConfigurations.reference.pkgs.callPackage ./pkgs/apps/omarchy-hyprland-titlebars.nix { inherit ((builtins.getFlake (toString ./.)).nixosConfigurations.reference.pkgs.hyprlandPlugins.override { hyprland = (builtins.getFlake (toString ./.)).nixosConfigurations.reference.config.programs.hyprland.package; }) mkHyprlandPlugin; }'`
     builds, and the `.so` is at that path.
   - Traps: Hyprland tracks main. If v0.3.0 does not compile against
     `e0e9c84`, stop and report: the fix is upstream's, not a patch
     here (§11).

## Rollback

Revert the PR:

- the apps and the switch disappear;
- `dua` returns;
- the Lua path goes back to `/usr/lib/...`, so the plugin is simply not
  found, as before;
- the ledger and its check go.

Nothing is stored on user machines, beyond what the apps write in their
own `~/.config` directories.

## Deviations

- **Step 5(c):** `data/arch-extras.nix` has no `kind = "system"`. Its
  kinds are `font`, `nixos-option`, `package` and `php-extension`. So
  `disktree-bin` is `kind = "package"`, with `attr` and `binary` set to
  `disktree`.
- **Step 6:** the existing omawrite, omacalc, omacut and aether rows
  gained `arch` names as well as `preinstall = true`. Upstream installs
  them through the same `omarchy-pkg-add` migrations, so they need the
  same mapping.
- **Step 6:** `readme-counts.sh --fix` also moved the skills count from
  seventeen to eighteen. That number is derived from the rc3 pin, which
  main had not refreshed, and is not from this change.
- **Step 1:** Signed's `poppler-qt6.pc` comes from `kdePackages.poppler`.
  Monologue also needed `pkg-config` and `libpulseaudio` to configure.
- **Step 8:** the ledger holds 237 unique names, not ~249. The figure 249
  counted duplicates across the lists. The check is registered in
  `uniformChecks`, not as a hand-written entry. The three red proofs ran
  on scratch copies of the check, identical code with `pkgs.omarchy`
  pinned, so the tree rev did not change and force an Omarchy rebuild
  while an install was in flight.
- **Step 10:** the red and green proofs read the generated check script
  (`nix derivation show`) rather than building it, for the same reason.
  The PR's CI builds it.
- **Found on the way:** #1569 left main's README counts at seventeen
  skills. Fixed separately in #1575 (§10), not in this branch.
- **Review fixes** (codex, on #1576):
  - The exported plugin in `flake.nix` was built against nixpkgs' Hyprland, not the input's. It now uses `hyprland.packages.<system>.hyprland`, the same Hyprland the omarchy package gets.
  - The session probe now runs one `command -v` per app.
  - Hype, Monologue and Signed now install their LICENSE.
