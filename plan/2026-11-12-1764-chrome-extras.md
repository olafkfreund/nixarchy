# Plan: Chrome gets Omarchy's bundled extensions and policy on edge

Lands as an `edge-candidate` carry after #1760 is promoted, beside #1763.

Approved decisions, from the spec:

- Edge only. In `pkgs/omarchy/default.nix` (or `quattro-user-files.sh`,
  which installPhase sources on edge, to stay under
  `checks.install-phase-budget`), rewrite `file:///usr/share/omarchy/` to
  `file://$out/share/omarchy/` in `default/chromium/policies/chrome-extensions.json`
  and `default/chromium/crx/updates.xml`. Expose
  `passthru.chromeExtensionsPolicy = isEdge`.
- `modules/nixos.nix`, beside `"chromium/policies/managed/omarchy.json"`:
  when `cfg.package.passthru.chromeExtensionsPolicy or false`, add
  `"opt/chrome/policies/managed/omarchy.json"` (from
  `default/chromium/policies/omarchy.json`) and
  `"opt/chrome/policies/managed/omarchy-extensions.json"` (from
  `chrome-extensions.json`). Not gated on Chrome being installed. Each file,
  and the existing Chromium `omarchy.json`, is built by a `runCommand` with
  `jq` deleting every name in `programs.chromium.extraOpts`.
- `override_update_url` is not added: upstream ships the policy without it,
  so it is documented as an upstream candidate.
- Native hosts and the theme colour need nothing new.
- Not shipped: `chrome-flags.conf`, the 1Password migration `1794391847`,
  and the maintainer tool. Migration `1794210626` is `not-needed` in #1763's
  ledger, citing this issue.

## Steps

1. Package: the two substitutions inside the edge-only block, and the
   passthru. → verify: `nix build .#omarchy` on edge, then
   `grep -r /usr/share result/share/omarchy/default/chromium/{policies,crx}`
   prints nothing; on the v4.5.0 scratch tree the package is unchanged
   (same drvPath as before the edit, compared in the same tree per §5).
   Traps: `--replace-fail` on each file; single quotes inside a
   single-quoted replacement break the build (pkgs/AGENTS.md); `$out`
   is written `'"$out"'` in the sourced file.
2. Module: the two `environment.etc` entries under the passthru condition,
   all three files filtered by `programs.chromium.extraOpts` names,
   plus an evaluation assertion (a case in the options suite, or a small
   eval check) that edge has both and v4.5.0 has neither. → verify:
   `nix eval` of `nixosConfigurations.reference.config.environment.etc`
   names on both trees.
   Traps: `lib.optionalAttrs`, not `mkIf`, inside an attrset merge (as
   modules/nixos.nix does); no `mkForce`.
3. `tests/chrome-policy.nix`, wired as `checks.chrome-policy` in `flake.nix`
   (uniformChecks): the spec's assertions on the package. → verify: green on
   both pins, and each spec break proof fails for its own reason.
   Traps: parse XML with a real parser (python3's xml.etree), not grep;
   an empty id list is a failure (§4).
4. `tests/coexistence/fixtures.nix`: a fixture setting
   `programs.chromium.extraOpts.DefaultBrowserSettingEnabled = true` and
   `programs.chromium.extensions`; in `tests/coexistence/default.nix` (the
   Chromium block near line 155), assert all four Chrome files and both
   Chromium files exist on edge, and that neither of ours carries
   `DefaultBrowserSettingEnabled`. `pkgs/AGENTS.md`:
   a short "Chrome's policy on edge (#1764)" section with what is not
   shipped and why; `docs/manual` browser page: one paragraph.
   → verify: `checks.coexistence`, `readme-counts.sh --check`.
   Traps: §14 (a fixture that cannot fail is worse than none); the docs
   style in docs/AGENTS.md.
5. The lead runs everything by §6 tier on both pins, commits per step,
   pushes the carry to `edge-candidate` and dispatches `omarchy-edge.yml`
   with `from_candidate=true`.

## Tests

- `checks.chrome-policy`, `checks.coexistence`, the options shards, and the
  generated-checks set on both pins.
- Break proofs: drop the `crx/updates.xml` substitution, delete a CRX,
  remove the module entries, stop filtering `extraOpts`.
- Not run: Chrome loading the extensions (unfree; no check may build it).

## Rollback

Revert the carry commits. Removing the two `/etc` files leaves Chrome as it
was before, with any force-installed extensions removed by Chrome itself on
its next policy read.
