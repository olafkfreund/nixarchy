# Plan: build the six omacom apps with CMake

Approved decisions (from the spec): CMake replaces qmake in all six packages;
`pkg-config` is added for hype, monologue and signed; the hand-written
`installPhase` stays (no upstream `install()` rules; binary is in the build
dir under the same name; `pkgbuild/` files still exist); versions and hashes
come from each package's `nix-update`; hype's fetch is named
`hype-${finalAttrs.version}` so upstream's CMakeLists reads the version from
the directory name; tests stay off; omacalc keeps its own desktop entry;
qmake-describing comments are corrected.

## Steps

1. `pkgs/apps/{hype,monologue,omacalc,omacut,omawrite,signed}.nix`: in
   `nativeBuildInputs` replace `qt6.qmake` with `cmake`, add `pkg-config` for
   hype, monologue and signed, add `cmake`/`pkg-config` to each file's
   function arguments, and fix comments that describe qmake.
   → verify: `nix eval .#<app>.drvPath` for all six.
   Traps: an editor hook may reformat `.nix` with nixpkgs-fmt; run `nix fmt`
   and read `git diff --stat` (CLAUDE.md §5).
2. `pkgs/apps/hype.nix`: `name = "hype-${finalAttrs.version}";` in its
   `fetchFromGitHub`, with a one-line comment saying why.
   → verify: the built binary carries `0.7.1`; with the line removed it
   carries `dev` instead (§1).
3. Run each package's `updateScript` (`nix run .#<app>.updateScript` from the
   repo root, or `nix-update --flake <app>`), then build all six.
   → verify: `nix build .#<app>` for each, at the package tier's gate (§6).
4. Run every check `generated-checks.sh` prints, and `checks.session`, by tier;
   `nix run .#update` afterwards changes none of the six.

## Tests

- Six package builds; the hype version break proof; `checks.session`;
  the full local tier; statix, deadnix, `nix fmt -- --ci`.

## Rollback

Revert the commit: each package returns to qmake at its old version and hash.
