# Plan: Correct Docker and shell PATH guidance

Nixarchy defaults to rootless Docker: `modules/nixos.nix:1507-1514` disables the rootful daemon and enables the rootless user daemon unless overridden. The security manual incorrectly describes rootful iptables behavior; the development tools manual already identifies the rootless daemon and its “enabled by default” wording is correct. The pinned nixpkgs revision in `flake.lock:1048` sets `writeShellApplication`'s `inheritPath ? true` (`pkgs/build-support/trivial-builders/default.nix:292`) and builds PATH from `runtimeInputs` followed by caller `$PATH` (line 321). Declared commands beat same-name PATH stubs; undeclared commands can run from the caller's PATH, making them environment-dependent. Correct all contrary guidance, and explicitly package the tools that doctor and apply call. Do not change Docker or builder behavior.

Reject the old rootful firewall text, unverified rootless port promises, a global `inheritPath = false` change, and a check that reads only a copied or source-level dependency list. Adding runtime inputs changes wrapper closure and command precedence to the pinned tools; the check must detect the module's actual wrapper without building a VM.
