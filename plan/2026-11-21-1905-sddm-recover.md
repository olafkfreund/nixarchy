# Plan: a greeter stranded by sleep is recovered on edge, as upstream recovers it

## What was decided in the spec

Quattro's `omarchy-system-sddm-recover` restarts SDDM after sleep when SDDM is active and no session holds a local seat (column 4 of `loginctl list-sessions --no-legend` starting with `seat`). Upstream runs it as `ExecStopPost=-` on four sleep units. On NixOS it names `sddm.service`, which does not exist: SDDM runs as `display-manager.service`. So it is patched.

The hook is a wrapper with its own PATH. A missing `awk` makes the seat test false, and the script would then restart SDDM, ending a desktop session. So the wrapper refuses to run when a command is missing. The changes:

- the hook is wired on the four sleep units under three gates;
- the rows change in `data/etc-overlay.nix` and `data/bin-ledger.nix`;
- three checks cover it: a stubbed cheap check, a decoupled `options` case and a `session` probe.

It lands as a carry on `edge-candidate`, and must be a no-op under `main`'s tag and older edge pins.

## Steps

1. **`pkgs/omarchy/quattro-script-ports.sh`: append the patch.**

   ```sh
   # Upstream names sddm.service; on NixOS SDDM is display-manager.service (#1905).
   f=$out/share/omarchy/bin/omarchy-system-sddm-recover
   [ ! -e "$f" ] || substituteInPlace "$f" \
     --replace-fail 'is-active --quiet sddm.service' 'is-active --quiet display-manager.service' \
     --replace-fail 'restart --no-block sddm.service' 'restart --no-block display-manager.service'
   ```

   - **Verify:** `.#omarchy` builds, and the shipped script holds both exact replaced lines.
   - **Traps:** the package tier gate, `vm-host-free.sh` for both install and edge, and load below 48. The file is sourced, so `install-phase-budget` holds; build it anyway.

3. **`modules/nixos.nix`: the wrapper and the hook.** In the top `let`, beside `registryFile`:

   ```nix
   # Why: spec/2026-11-21-1905-sddm-recover.md — a missing awk reads as "no seat" and restarts SDDM.
   hasSddmRecover = builtins.pathExists "${inputs.omarchy}/bin/omarchy-system-sddm-recover";
   ```

   In `config`, the wrapper:

   ```nix
   sddmRecover = pkgs.writeShellApplication {
     name = "omarchy-sddm-recover";
     runtimeInputs = [ config.systemd.package pkgs.gawk ];
     inheritPath = false;
     text = ''
       for c in systemctl loginctl awk; do
         command -v "$c" >/dev/null || { echo "omarchy-sddm-recover: $c not found" >&2; exit 1; }
       done
       exec ${cfg.package}/bin/omarchy-system-sddm-recover "$@"
     '';
   };
   ```

   `cfg` and `config` are needed, so this goes in a `let` inside `config` or at the top with `config.` references; pick whichever the file already does for `cfg.package`.

   In `systemd.services`, after the fprintd `optionalAttrs`:

   ```nix
   // lib.optionalAttrs (cfg.displayManager && config.services.displayManager.sddm.enable && hasSddmRecover) (
     lib.genAttrs [ "systemd-suspend" "systemd-hibernate" "systemd-hybrid-sleep" "systemd-suspend-then-hibernate" ] (_: {
       enableDefaultPath = lib.mkDefault false;
       serviceConfig.ExecStopPost = [ "-${sddmRecover}/bin/omarchy-sddm-recover" ];
     })
   )
   ```

Then eval the rendered `systemd.units."<u>.service".text` for all four units on `nixosConfigurations.vm`: each must contain `ExecStopPost=-/nix/store/…-omarchy-sddm-recover/bin/omarchy-sddm-recover` and no `PATH=`. 4. **`data/etc-overlay.nix`: the four rows.** Each changes to `class = "native"` and keeps `edge = "only"`, with this reason: "`systemd.services.<unit>.serviceConfig.ExecStopPost` in modules/nixos.nix runs upstream's script through a wrapper with its own PATH, patched from `sddm.service` to `display-manager.service`; gated on nixarchy's SDDM and a pin that ships the script (#1905)." `<unit>` is the row's own unit.

5. **`tests/sddm-recover.nix` (new), and `"sddm-recover"` in `flake.nix`'s name list before `"session-journal-race"`.** Run `git add` before building (§5).

   The check is modelled on `tests/update-available.nix`:
   - `shipped = pkgs.nixarchy-omarchy or pkgs.omarchy`, and `script = "${shipped}/share/omarchy/bin/omarchy-system-sddm-recover"`.
   - If the script is absent, `echo "sddm-recover: skipped, this pin ships no omarchy-system-sddm-recover"; touch $out`.
   - Otherwise it builds stubs in `fake-bin` with `printf` (no heredoc, §5):
     - `systemctl` appends `$*` to `$CALLS`; for `is-active` it exits per `$DM_ACTIVE`.
     - `loginctl` exits 1 when `$LOGIN_FAIL=1`, and otherwise prints `$SESSIONS`.
   - PATH is `fake-bin` plus `gawk` plus coreutils.
   - Each case resets `$CALLS`, runs `bash "$script"`, requires exit 0, and counts lines matching exactly `restart --no-block display-manager.service`:

     | case | input | restarts |
     |---|---|---|
     | seated | a `seat0` user row plus a manager row | 0 |
     | seatless | manager and sshd rows only | exactly 1 |
     | DM inactive | `DM_ACTIVE=0` | 0 |
     | logind fails | `LOGIN_FAIL=1` | 0 |

   - Only after the cases, `! grep -q 'sddm\.service' "$script"`.
   - **Verify:** builds and prints four PASS lines.

6. **`tests/options.nix`: a `sddmRecover` case**, in the same attrset as `displayManager`, so it lands in the same region.

   ```nix
   sddmRecover =
     let
       units = [ "systemd-suspend" "systemd-hibernate" "systemd-hybrid-sleep" "systemd-suspend-then-hibernate" ];
       hasScript = builtins.pathExists "${inputs.omarchy}/bin/omarchy-system-sddm-recover";
       hooked = c: builtins.filter (u: builtins.any (e: pkgs.lib.hasInfix "omarchy-sddm-recover" e)
         (pkgs.lib.toList ((c.systemd.services.${u} or { }).serviceConfig.ExecStopPost or [ ]))) units;
     in {
       on = hooked (configWith { displayManager = true; }) == (if hasScript then units else [ ])
         && hooked (configBeside { programs.nixarchy.displayManager = false; services.displayManager.sddm.enable = true; }) == [ ]
         && hooked (configBeside { services.displayManager.sddm.enable = pkgs.lib.mkForce false; }) == [ ];
       off = hooked (configWith { displayManager = false; }) != [ ];
     };
   ```

   Check whether `inputs` is in scope there (it is used at line ~1894), and whether `pkgs.lib` or `lib` is the local spelling.
   - **Verify:** `options-shards` (cheap), then all four `options-*` shards, which is the VM tier.
   - **Traps:** the case must be `on` true and `off` false. The broken-case report prints both.

7. **`tests/session.nix`: the probe**, right after `machine.wait_until_succeeds("loginctl list-sessions | grep -q greeter")`, inside `with subtest("sleep units recover a stranded greeter (#1905)"):`.

   ```python
   recover_units = ["systemd-suspend", "systemd-hibernate", "systemd-hybrid-sleep", "systemd-suspend-then-hibernate"]
   shipped = machine.succeed("test -e /run/current-system/sw/share/omarchy/bin/omarchy-system-sddm-recover && echo yes || echo no").strip() == "yes"
   ```

   - **If `shipped`:**
     1. For each unit, `systemctl show -p ExecStopPost --value <u>`. Split the output on `}` and keep the entry with `omarchy-sddm-recover`; assert it exists, naming the unit, and holds `ignore_errors=yes`. Take its `path=` field, and require it to be the same for all four.
     2. Preconditions: `systemctl is-active display-manager.service` succeeds, and `loginctl list-sessions --no-legend` succeeds with `awk '$4 ~ /^seat/'` non-empty.
     3. Record `systemctl show -p InvocationID --value display-manager.service`.
     4. Run `systemd-run --quiet --wait --pipe --collect <path> 2>/tmp/recover.err; echo rc=$?`, then assert `rc=0` and that `/tmp/recover.err` is empty, printing it otherwise.
     5. `wait_until_succeeds("! systemctl list-jobs --no-legend | grep -q display-manager.service", timeout=30)`.
     6. Assert `InvocationID` is unchanged and display-manager is still active.
   - **Else:** assert that no unit's `ExecStopPost` contains `omarchy-sddm-recover`.
   - **Verify:** `checks.session` (VM tier: 0 busy runners, and no edge `verify` in flight).

Revert the carry's commits on `edge-candidate`. `main` is untouched. The hook is `-`-prefixed, so on a deployed host a broken hook fails only itself, and the wrapper refuses rather than restarting.
