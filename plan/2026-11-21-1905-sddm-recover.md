# Plan: a greeter stranded by sleep is recovered on edge, as upstream recovers it

## What was decided in the spec

Quattro's `omarchy-system-sddm-recover` restarts SDDM after sleep when SDDM is active and no session holds a local seat. Upstream runs it via `ExecStopPost=-` on four sleep units. On NixOS it names `sddm.service`, which does not exist (SDDM runs as `display-manager.service`), so it is patched.

- **Hook.** A wrapper with its own PATH (`systemd`, `gawk`, `inheritPath = false`) and a guard that refuses when `systemctl`, `loginctl` or `awk` is missing. The guard exists because a missing `awk` reads as "no seat" and the script would then restart SDDM, ending a desktop session.
- **Where it is wired.** `ExecStopPost` on `systemd-suspend`, `systemd-hibernate`, `systemd-hybrid-sleep` and `systemd-suspend-then-hibernate`, with `enableDefaultPath = lib.mkDefault false`.
- **Gates.** `cfg.displayManager && config.services.displayManager.sddm.enable && builtins.pathExists "${inputs.omarchy}/bin/omarchy-system-sddm-recover"`. Under the tag and older edge pins nothing changes.
- **Rows.** The four `data/etc-overlay.nix` rows become `native`, and a `data/bin-ledger.nix` `patch` row is added (`edge = "only"`).
- **Checks.** A cheap stubbed `checks.sddm-recover`, a decoupled `options` case `sddmRecover`, and a `session` greeter-phase probe.
- Lands as a carry on `edge-candidate`.

## Steps

1. **`pkgs/omarchy/quattro-script-ports.sh` (append):** patch both `sddm.service` lines of `$out/share/omarchy/bin/omarchy-system-sddm-recover` to `display-manager.service` with `--replace-fail`, only if the file exists. Add a line to `pkgs/AGENTS.md#quattro-script-ports` naming it.
   - **Verify:** `.#omarchy` builds, and `grep -c display-manager.service` in the shipped script prints 2.
   - **Traps:** the install-phase budget (`checks.install-phase-budget`). The file is sourced, so the budget holds. The tag ships no such file, so the `[ -e ]` guard is required.
2. **`data/bin-ledger.nix`:** add an `omarchy-system-sddm-recover` row with `edge = "only"` and `class = "patch"`, and a reason naming the unit-name patch (#1905). Add any `allow` the ledger's what-it-does check demands, for the `systemctl restart`.
   - **Verify:** `checks.bin-ledger` under both pins.
3. **`modules/nixos.nix`:** add `sddmRecover` in the `let` (a `writeShellApplication`, per the spec), and a `// lib.optionalAttrs (<the three gates>) (lib.genAttrs [ the four units ] (_: { … }))` after the fprintd `optionalAttrs` in `systemd.services`.
   - **Verify:** eval `nixosConfigurations.vm`'s `config.systemd.units."systemd-suspend.service".text`. It must show the hook and no `PATH=`.
   - **Traps:** `nix fmt` after edits (the nixpkgs-fmt hook, §5); `inputs` is in scope (line 1).
4. **`data/etc-overlay.nix`:** change the four rows to `class = "native"` and keep `edge = "only"`. Each reason names the option, the wrapper and the patch.
   - **Verify:** `checks.etc-overlay`.
5. **`tests/sddm-recover.nix` (new) and `flake.nix`'s name list:** add `"sddm-recover"` before `"session-journal-race"`. The check is a runCommand modelled on `tests/update-available.nix`. It uses `shipped = pkgs.nixarchy-omarchy or pkgs.omarchy`, and if the script is absent it echoes `skipped` and writes `$out`. Otherwise it runs four stub cases (seated, seatless, DM inactive, loginctl fails) plus a `grep` that `sddm.service` is absent.
   - **Verify:** builds; red when step 1 is reverted.
   - **Traps:** printf, not a heredoc, inside the `''` string (§5); pipefail.
6. **`tests/options.nix`:** add a `sddmRecover` case next to `displayManager`, with the fixtures named in the spec. `hasScript` is `builtins.pathExists "${inputs.omarchy}/bin/omarchy-system-sddm-recover"`. `hooked c` counts the units whose `lib.toList (c.systemd.services.${u}.serviceConfig.ExecStopPost or [ ])` has an entry containing `omarchy-sddm-recover`, with `c.systemd.services.${u} or { }`.
   - **Verify:** `options-shards` (cheap), then the shard holding the region (VM tier).
   - **Traps:** the case must sit in an existing region, or `options-shards` fails. The case's `on` must be true and its `off` false.
7. **`tests/session.nix`:** add the greeter-phase probe right after `loginctl list-sessions | grep -q greeter`, as the spec sets out.
   - **Verify:** `checks.session` (VM tier, 0 busy runners).
8. **Red proofs** (spec, Verification): revert step 1; drop gawk; drop one unit; drop `cfg.displayManager`. Capture each failure, then restore with `git checkout HEAD --` (§5).
9. **Under `main`'s pin, in a scratch `git worktree add --detach` tree:** restore `flake.nix`'s two pin copies from `origin/main`, run `nix flake update omarchy`, then run the generated checks, `.#omarchy`, `sddm-recover` (skipped) and the `options` shard.
10. **Push to `edge-candidate`** only when no `omarchy-edge` run is in progress. Dispatch with `from_candidate=true`, then watch it.

## Tests

- **Cheap:** `sddm-recover`, `etc-overlay`, `bin-ledger`, `options-shards`, and every target `generated-checks.sh` prints, under both pins.
- **Package tier:** `.#omarchy` under both pins.
- **VM tier:** `session` under the carry's pin, plus the `options-*` shard holding the case, under both pins where the gate allows.

## Rollback

Revert the carry's commits on `edge-candidate`. Nothing touches `main`, and the hook is `-`-prefixed, so on a deployed host a broken hook fails only itself.
