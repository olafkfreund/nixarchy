## Facts to use verbatim

- The palette is "installed, off by default"; Omarchy's own menu is the
  default; **Setup ▸ Defaults ▸ Menu** switches with no rebuild (README:501,
  plugins.md:394).
- `nixarchy-verify` ends with `N passed, N failed, N worth a look`
  (`pkgs/verify.sh:1372`).
  - `✓` is ok, `✗` is a failure, `·` is worth a look.
  - It runs inside a running Omarchy session.
- Edge's ported features (#1280) already list: language switching, the
  fingerprint resume hook, removing fingerprint authentication, and the
  hidden passwordless-sudo toggle. #1386 adds that `omarchy agent account
  use` reaches the next `claude`, `codex` or `grok` typed in a shell.
- Edge's fallback (#1383, #1394): when the newest `quattro` fails, the run
  publishes `main` on the last `quattro` that passed and files or updates
  the `omarchy-edge` issue.
- The menu folder (#1414): a top-level **Nixarchy** folder right after
  Trigger holds nixarchy's panels, and Nixi is its last row.
- The dev label (#1373): on the dev channel, the version label names the
  checkout commit being built, not nixarchy's pin.
