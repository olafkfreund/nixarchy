# Plan: the config writers take apply's lock and keep the files they edit

## Approved decisions, with the helper's full contract

**The lock:** `${XDG_STATE_HOME:-$HOME/.local/state}/nixarchy/applied/lock`,
fd 9.

`pkgs/writer-lock.sh` is a sourced bash file with no top-level side effects.
Writers splice it in with `builtins.readFile`. `pkgs/pkg-new.sh` gets it
through an `@writerLock@` token, which both the wrapper and
`tests/pkg-new.nix` replace with `lib.replaceStrings`. Its state directory is
`nx_state=${XDG_STATE_HOME:-$HOME/.local/state}/nixarchy`, and the lock file
is `$nx_state/applied/lock`.

- **`nx_lock`**
  - If `${NIXARCHY_LOCK_HELD:-}` = 1, it returns 0.
  - Else, in order: `mkdir -p "$nx_state/applied"`, `exec 9>>"$nx_state/applied/lock"`
    and `flock -w 5 9`. Each failure calls `nx_refuse` with its own cause:
    - "cannot create <dir>"
    - "cannot open <lock>"
    - "a write or an apply is running -- try again when it finishes. Nothing
      was changed."
  - On success it exports `NIXARCHY_LOCK_HELD=1` and sets the global
    `NX_OWNER=1`.
- **`nx_unlock`**: `unset NIXARCHY_LOCK_HELD`. If `NX_OWNER=1`, it runs
  `exec 9>&-` and sets `NX_OWNER=0`. It is idempotent.
- **`nx_put SRC DST`**
  - If DST exists: it refuses unless `[ -f DST ] && [ -w DST ]` (both follow
    symlinks), naming DST as "not a writable file". It then runs
    `mkdir -p "$nx_state/backup"` and `bak=$(mktemp -p "$nx_state/backup")`.
    If `cp --reflink=never -- DST "$bak"` fails, it refuses before DST is
    opened.
  - If DST is absent, there is no backup.
  - `trap '' INT TERM HUP QUIT XFSZ`, then `cat -- SRC > DST`, keeping its
    status, then `trap - INT TERM HUP QUIT XFSZ`.
  - **On success:** `rm -f SRC "$bak"`, and return 0.
  - **On failure, with a backup:** if `cat -- "$bak" > DST` succeeds, it runs
    `rm -f "$bak" SRC` and refuses with "<DST> could not be written; its
    previous content is restored". Otherwise it refuses with "<DST> could not
    be written or restored; its previous content is at <bak>", and keeps
    `$bak`.
  - **On failure, with no backup:** it runs `rm -f DST SRC` and refuses.
- **`nx_sed DST ARGS...`**: `tmp=$(mktemp -p "$nx_state")`, then
  `sed "${@:2}" -- "$1" > "$tmp"` (callers pass sed options and `-e`
  expressions as ARGS), then `nx_put "$tmp" "$1"`. If sed fails, it runs
  `rm -f "$tmp"` and returns sed's status; DST is untouched.
- **`nx_commit SNAPSHOT WORK DST CMD`**: if `cmp -s SNAPSHOT DST` fails, it
  refuses with "<DST> changed while <CMD> was running; nothing was written.
  Run it again." Otherwise it runs `nx_put WORK DST`.
- **`nx_refuse MSG`**: `nx_unlock`, then `printf '%s\n' "MSG" >&2`. If
  `omarchy-notification-send` is on PATH, it runs
  `omarchy-notification-send -u critical "nixarchy" "MSG" 9>&- || true`. It
  exits 75.

**Global rules:**
- Every success notification and every `exec` is preceded by `nx_unlock`.
- Every child started while the lock is held gets `9>&-`.
- Temp files go to the state directory, never `~/.config/nixarchy/`.
- Each writer has one EXIT trap that runs `nx_unlock` and removes its temp
  files. A recovery backup that `nx_put` kept is not removed.
- `util-linux` joins every writer's `runtimeInputs`, and `cfg.package` joins
  those missing it, for notifications: catalogue-diff, language-select,
  service-disable, opt-remove, search.

**Placement:**

| Placement | Writers |
|---|---|
| Lock first | catalogue-diff (when `add=true`, i.e. `--add` or `--add-one`), language-select, service-disable, app-enable, and app-disable (before the `[ -f "$file" ]` at 2383, so both branches are inside) |
| Prompt first, then lock and re-check | pkg-remove, pkg-undraft, opt-remove, and service-enable, whose SSH gate is re-decided under the lock |
| Copy and commit | pkg-add (`nx_commit`), and pkg-new (draft built in the state directory, committed under the lock) |
| Per insert | search's `insert_line`; the batch restore is removed |

**`nixarchy-apply` messages:** "a write or another apply is running (it may
be waiting at a prompt); try again when it finishes" (4432), and "waiting
for a write or another apply to finish..." (4435).

**Full-disk outcome (approved with the spec):** the write is restored, or a
full backup is kept at a named path.

2. **`tests/writer-lock.nix` (new), helper cases**, plus `"writer-lock"` in
   `flake.nix`'s `uniformChecks` (1820).
   - Setup: a runCommand with bash, coreutils, util-linux, gnused and
     diffutils, and `HOME`/`XDG_STATE_HOME` under `$TMPDIR`.
   - **Helper cases:**
     1. **Contention:** a holder runs `flock "$lock" sleep 30 &`. A
        subshell's `nx_lock` exits 75 within 5-7 s, with "a write or an
        apply is running" on stderr.
     2. **Nesting:** the same holder, with `NIXARCHY_LOCK_HELD=1`. `nx_lock`
        returns 0 in under 1 s.
     3. **Stale handshake:** a non-owner with `NIXARCHY_LOCK_HELD=1` calls
        `nx_unlock`. A child `env` then shows no `NIXARCHY_LOCK_HELD`.
     4. **Fail closed:** `chmod 0500` the state directory's parent. `nx_lock`
        exits 75 with "cannot create".
     5. **Keeps the file:** a target at 0640 reached through a symlink.
        After `nx_put`, `[ -L link ]`, the inode (`stat -L -c %i`) is equal,
        the mode is 640, and the content is the new content.
     6. **Read-only target:** a 0444 target. `nx_put` exits 75, and the
        content and inode are unchanged.
     7. **Interrupted write:**
        - `mkfifo src`. Under `set -m`, run `nx_put src dst &` and take
          `pgid=$!`.
        - `exec 7>src` holds one writer fd open. Write the first half, sleep
          0.5, `kill -INT -$pgid`, write the second half, `exec 7>&-`, and
          wait.
        - dst then holds all of the new content.
     8. **Failed write, restored:** old content 500 B, new content 2048 B.
        `( ulimit -S -f 1; nx_put new dst )` exits 75, and dst is the old
        500 B, byte-equal. A 1 KiB limit lets the 500 B backup copy succeed
        and fails the 2048 B write.
     9. **Commit refusal:** the snapshot is A, the target is B and the work
        file is C. `nx_commit` exits 75, and the target stays B.
   - **Verify and §1:** `nix build .#checks.x86_64-linux.writer-lock`. Then
     each of these breaks must turn its case red:

     | Break | Case |
     |---|---|
     | `nx_lock` made `return 0` | 1 |
     | `nx_put`'s cat replaced with `mv SRC DST` | 5 |
     | the signal-ignore removed | 7 |
     | the restore removed | 8 |
     | `nx_commit`'s `cmp` removed | 9 |

   - Traps:
     - `git add` before building (§5);
     - no heredoc inside a `''` string; use `printf` (§5);
     - in a `''` string, `\$` is a literal backslash (§5);
     - build `checks.grep-q-pipefail` too.
