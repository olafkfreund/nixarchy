## Deviations

- **Step 6, first attempt, found a real bug rather than a bad frame.**
  `nix build .#demo-scene-menus` failed its own verify step (0 of 10 sampled
  transitions moved; no OCR match for `/install/` or `/style/`), and the
  frames it did produce showed the bare desktop throughout both holds — the
  palette never opened. Root cause: `OmarchyMenu.qml` imports `MenuModel.js`
  from `/run/current-system/sw/share/omarchy`, which nixarchy installs never
  linked. Fixed upstream as #1069 (PR #1071, merged to `main` as `ba5dd18`).
  Work on this plan paused until that landed, then resumed on a worktree
  rebased onto `ba5dd18`. The plan's own steps did not change; the pictures
  in step 6 are the fixed scene's frames, not a rebuild from the original
  attempt.
- **`docs/AGENTS.md`, "Driving the menu in a recording", carried a wrong
  claim** found while investigating #1069: "`omarchy menu close` addresses
  Omarchy's own menu and does nothing to this one" is false. It resolves to
  `omarchy-shell shell hide omarchy.menu`, which calls nixarchy-menu's own
  `close()` — the same function a second `toggle` reaches, with the same
  dictation trap when voice is on. Corrected in the same commit as this plan
  file, since neither is code the plan's steps otherwise touch.
- **Step 6, 1600x875 crops** use `-gravity north`, not `center`. The demo frames are 16:10 (1280x800). Scaled to 1600 wide they are 1000 tall, and a centred crop to 875 cut off the top bar with its snowflake menu button, so the picture was not a whole desktop (docs/AGENTS.md house style). Cropping from the bottom loses only wallpaper. The 760x475 targets are 16:10 and need no crop. Finished by the orchestrator (Opus) after the coder handed step 8 back.
- **Review follow-up:** `close()` returns 1 when the menu is still open after 3 s, and `shot()` skips the frame rather than toggling an open menu, which would reach nixarchy-menu's `close()` and its dictation path. The comment above it now says opening is IPC and closing is Escape. Raised by the independent Opus review of #1072, and fixed by the orchestrator.
