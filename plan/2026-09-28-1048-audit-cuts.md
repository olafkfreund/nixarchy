# Plan: the same code, written once

## Approved decisions, carried from the spec

- **Cut 2 (shared shell helpers) is dropped.** The `red`/`dim`/`bold` copies
  are all in `nix-bin` (standalone by decision), and the `pkgs/*.sh` helpers
  differ in behaviour (`say()` has four variants).
- **Cut 1:** `uniformChecks`, a sorted list of **41** names (the 42 uniform
  registrations minus `options`), registered with
  `lib.genAttrs uniformChecks (n: import ./tests/${n}.nix { inherit inputs; pkgs = pkgsFor.${system}; })`.
  The explicit entries are deleted, and `options` stays explicit and untouched.
- **`checks.test-registration` is handed the list as data** (`uniform =
  uniformChecks`). It treats `imported = grep-found ∪ uniform`, and its floor
  of 50 applies to the union. Without that, about 46 literal imports would
  trip the floor.
- **`tests/lib.nix`** provides `vmPackage name` and `okBad`, and goes on
  `test-registration`'s exempt list with its reason.
  - `vmPackage` replaces the pick-by-name blocks in `apply-detach-interface`,
    `apply-imports`, `apply-staging` (2) and `branch-guard`. `options.nix`'s
    two stay.
  - `okBad` replaces the byte-identical `ok`/`bad` lines in `apply-staging`,
    `branch-guard`, `mise-launchers`, `pkg-new`, `skills-relink` and
    `try-preflight`.
- **Proof:** every check's derivation is identical before and after, except
  `test-registration`. Differences caused only by the git revision or the
  flake source path are expected (§5: every commit changes them) and are
  shown to be only that.

## Steps

**0. Before any local build or heavy evaluation:** `gh run list … | length`
must print 0, **checked in its own command and read first.**

1. **Baseline:** record the approved-spec commit (`ac34299`) and, from a clean
   tree there, `nix eval --json` the `drvPath` of every check except
   `options`, into `baseline.json` in the scratchpad.
   → verify: the file has 86 or more entries (88 checks, less `options`,
   plus any added since), with no nulls.
2. **`tests/lib.nix`**, and add it to `test-registration`'s exempt list with
   its reason.
3. **Cuts 3 and 4:** replace the 5 `vmPackage` sites and the 6 `okBad` sites.
   Each file imports `./lib.nix` with `{ inherit inputs; }`. For files that
   take only `{ pkgs, … }` and no `inputs`, `okBad` doesn't need `inputs`, so
   `lib.nix`'s `inputs` argument gets a default of `null`, and `vmPackage` is
   only called where `inputs` exists.
4. **Cut 1:** `uniformChecks` plus `genAttrs` in `flake.nix`, the 41 explicit
   entries deleted, and `test-registration` given `uniform = uniformChecks`,
   with its union and floor. Then `nix fmt`, and read `git diff --stat` (the
   nixpkgs-fmt hook, §5).
   → verify: `nix eval .#checks.x86_64-linux --apply builtins.attrNames`
   lists exactly the names it listed at `ac34299`.
5. **The proof.** Commit, then evaluate every check's `drvPath` again, into
   `after.json`. For each name whose `drvPath` differs, run `nix-diff` and
   classify:
   - **expected:** the only differences are the flake source's store path or
     `nixarchyRev` (a different commit), or the check is `test-registration`;
   - **anything else is a failure of the refactor**, and gets fixed, not
     explained away.
   The per-check classification is recorded in the PR.
   → verify: zero unexplained differences.
6. **Red (§1), from a committed baseline:**
   - drop one name (for example `swap-guard`) from `uniformChecks` without
     restoring its entry: `test-registration` must name `tests/swap-guard.nix`
     as unregistered;
   - remove `lib.nix` from the exempt list: `test-registration` must name
     `tests/lib.nix`.
   Each temporary commit is dropped with `git reset --hard` to the baseline,
   and the tree is shown clean.
7. **Build** `test-registration` and the ten touched checks (`apply-*`,
   `branch-guard`, `mise-launchers`, `pkg-new`, `skills-relink`,
   `try-preflight`), once, even where their derivations are proven
   identical.
8. **Lint and PR:** `nix fmt -- --ci`, statix, deadnix. Squash the
   implementation, keeping the artifact commits. `Closes #1048`, with a
   comment on #1048 recording that cut 2 was dropped and why.
