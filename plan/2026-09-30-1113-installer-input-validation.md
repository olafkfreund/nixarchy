# Plan: Validate installer inputs before installation

Implement only after #1089 merges. Fetch and rebase `fix/1113-installer-input-validation` onto current `origin/main` first, read the rebase status, and recheck the function references below. #1089 changes disk safety in the same `installer/install.sh`; preserve all of it. No workflow edit or local VM run is authorized by this plan.

Approved behavior: use the existing shared validators for wizard, answers, and `--host`; preserve ASCII name syntax while enforcing 32-byte usernames and 63-byte hostnames; reject `root`, `bin`, `daemon`, `nobody`, `sshd`, `systemd-network`, `systemd-resolve`, and `nixbld*`. Reject an answers-file timezone unless it is a regular zone file inside `TZDIR`; reject absolute and parent-traversal names. Match an answers-file keymap as a literal basename of an existing `.map.gz` file under `KEYMAPS`, never as a `find` pattern. Refuse invalid answers with the existing specific error and exit 2, without a fallback. Parse nmcli's escaped terse fields so a colon or backslash in an SSID is decoded and passed unchanged to `nmcli device wifi connect`, while preserving deduplication, signal sort, and security display. A failed write of `nixarchy-hardware.nix` stops `generate_hardware_config` with a file-naming error; unavailable hardware detection remains best-effort.
