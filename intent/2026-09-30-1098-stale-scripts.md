# Intent: Remove stale desktop script instructions and commands

## Problem

All five findings in the **Stale scripts** group of #1098 still apply, with two qualifications:

- The pinned Omarchy `c668141` source launches Spotify, Signal and ChatGPT through `/usr/bin/...` in their install scripts. `pkgs/omarchy/default.nix` patches the separate Spotify and Signal **launch** scripts, but does not patch these three **install** scripts; `tests/session.nix` explicitly exempts them from its `/usr` sweep.
- `pkgs/omarchy/nix-bin/omarchy-default-agent` maps Antigravity to `agy` for mise, but its installed-command probe still tests the saved id `antigravity`. A working `agy` can therefore be treated as missing.
- `pkgs/omarchy/nix-bin/omarchy-cursor-set` still calls `hyprctl keyword env`. Current Hyprland documentation describes the Lua `hyprctl eval` interface and no longer lists `keyword`. The stale syntax is confirmed; its exact runtime failure has not been measured.
- `pkgs/omarchy/nix-bin/omarchy-snapshot` offers every row from `snapper list`, including snapshot 0, then constructs `/home/.snapshots/0/snapshot` for a selected row. Snapshot 0 is the current state, not a restorable snapshot directory.
- `pkgs/omarchy/nix-bin/nixarchy-preview` advises `sudo usermod -aG kvm $USER`. NixOS group membership must be declared in the configuration and rebuilt, so that command does not persist.

No finding was already fixed or dropped. The install-script claim is specifically about the installer commands, not the launchers already patched in `default.nix`.

## Proposed outcome

Installing the three apps opens the installed command on NixOS. Selecting Antigravity recognizes `agy` on PATH. Cursor theme changes use the current session interface and retain the intended cursor behavior. Snapshot restore offers only usable snapshots. Preview tells users how to grant persistent KVM access through their NixOS configuration.

## Affected users and systems

Desktop users of the Omarchy install menu, default-agent menu, cursor theme hook, snapshots and VM preview; the vendored Omarchy package and its Nix replacements; associated cheap checks and session coverage.

## Constraints

- This is a partial fix: use `Refs #1098`, not a closing keyword. Leave the issue's other groups untouched.
- Keep upstream changes as narrowly anchored patches, and verify the packaged result. Preserve user package overrides and existing declarative app selection.
- Do not edit installer or MicroVM files reserved for the criticals PR, or `tests/options.nix`.
- Prove any new check fails when the old behavior is restored. No Nix builds or PRs at this gate; the branch stays local until the push hold lifts.
