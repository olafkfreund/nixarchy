## Decisions (from the approved spec)

1. **One carry on `edge-candidate`**, as #1684. The artifacts go to `main`
   on `fix/1736-quattro-255acd9`. Pin quattro's newest commit at carry time,
   `255acd9` today: both `flake.nix` copies (input `url`, `omarchyVersion`),
   plus `flake.lock`, then a `from_candidate=true` dispatch (§8).

   - `agent-local-use.upstream.sh` becomes upstream's new `use` block,

     `run=(omarchy-launch-floating-terminal-with-presentation "omarchy-agent-local ${agent_local_args[*]@Q}")`,

   - Upstream's `envs.lua` line arrives with the pin.
   - Migration `1792902457` is `edited`: `omarchy-pkg-add qtengine` removed.
   - The fallback order is in step 3.
4. **Papers for Evince:**
   - `papers` is installed, and the `evince` row is removed.
   - Migration `1794165002` is `edited`, with three cases: an absent file, a
     regular writable file, and a symlink that is left alone and reported.
   - The marker is written in each case.
5. **Ledgers reconcile** additions, removals and renames. The five other
   migrations need no row: all are system or hardware only, as read for the
   spec.
6. **Verification:** every reachable check locally by §6 tier. The qtdiag
   measurement runs in `checks.session` on edge CI, since `session` does not
   run locally.

**Decision 7, added at plan time (a finding the spec did not have).** Evince
is hard-coded in three more places, and each must switch with the pin:

- `pkgs/omarchy/default.nix:294`: the runtime list's `evince # PDF viewer`.
- `modules/nixos.nix:2362`: `xdg.mime.defaultApplications."application/pdf" = "org.gnome.Evince.desktop"`.
- `tests/session.nix:2201`: the session's PDF-handler assertion.

`main`'s v4.5.0 still ships Evince, so the choice is derived from the pinned
source. `pkgs/omarchy/default.nix` reads its `src` input at evaluation
(`src` is a flake input path, not a derivation output, so there is no IFD)
and exposes it through passthru:

- `passthru.pdfViewer`: `papers` if `${src}/install/omarchy-base.packages`
  names `papers`, else `evince`;
- `passthru.pdfDesktop`: `org.gnome.Papers.desktop` or
  `org.gnome.Evince.desktop`;
- `passthru.hasQtengine`: `builtins.pathExists "${src}/config/qtengine"`.

Every site reads these, so one line holds under both pins (§8).
