# Plan: `@generation` and `@window` in mirror-vm batches

## Approved decisions (self-contained)

Everything is in `pkgs/omarchy/skills/ai-mirror/mirror-vm`, stdlib Python.

- **Markers.**
  - The table: `MARKERS = {'frame': '@last', 'generation': '@generation', 'window': '@window'}`,
    `refs = {k: None for k in MARKERS}`,
    `why = {'frame': 'before any screenshot', 'generation': 'no generation seen yet', 'window': 'before any launch'}`.
  - For each step, for each key whose `args.get(key) == marker`: substitute
    `refs[key]`, or raise `ValueError(f'step {i}: "{marker}" {why[key]}')` if
    it is `None` (exit 1, nothing sent).
  - Only exact top-level values match. A step that doesn't use a marker is not
    checked, and missing keys are never filled.
- **Updates** happen only when `not err and isinstance(body, dict)`, including
  in the grant loop.
  - **`frame`:** a `screenshot` result's `frame` when it is a `str`.
  - **`generation`:** from the grant's confirming `status`, then from any
    result whose `generation` is an `int` and not a `bool`.
  - **`window`, set:** a `launch` result with a `window` string that is not
    blank after `strip()`.
  - **`window`, cleared by a launch:** any other successful `launch` sets it to
    `None`, and `why['window'] = 'after a launch that did not return exactly one window'`.
  - **`window`, cleared by a close:** a successful `window` step with
    `args.action == 'close'` and an `args.address` (after substitution) equal
    to `refs['window']` sets it to `None`, and
    `why['window'] = 'after that window was closed'`.
  - **Not set otherwise:** no other tool touches `window`.
- **Docs.**
  - The `--help` description names the three markers.
  - `SKILL.md`'s example becomes launch → type → screenshot with
    `@generation`/`@window`.
  - One line on what clears `@window`, and the limit: a window that exits on
    its own leaves it set, and the guest's focus check (`wrong_target`)
    refuses typing into it.
- **Test:** `tests/mirror-vm.nix` (a `runCommand`) plus
  `tests/mirror-vm-fake-socat.py`, a fake guest server on `PATH`. The script
  runs with `HOME=$TMPDIR` and a `vsock-cid` file. There are 10 cases (step 3
  lists them). The check is registered in `flake.nix` checks, and
  `generated-checks.sh` builds it in CI with no YAML.
