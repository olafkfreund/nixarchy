# Plan: mise installs and controls nothing on a nixarchy machine

Owner's rule, 2026-11-05: "strip mise from the code, I do not want mise to install or
control anything on our machines." The owner approved the intent, the spec and every
recommendation in them.

**Who does what.** Codex and agy are the only coders and neither can build. The Opus
supervisor runs every check, reads every result and makes every commit. No coder runs
`mise`, changes a real `$HOME`, or runs anything that can print the environment (`env`,
`export`, `set`, `declare -x`, `printenv`): it holds real tokens. A step's "verify" is
run by the supervisor after the coder hands back.

**Line numbers.** Repo lines are at `5b547be1`, this branch's base. Upstream lines are
Omarchy v4.5.0, whose tree is `/nix/store/fvx3schlkir5mp8kb7lz2c677ckqf7r3-source`.
Step 0 re-checks them after #1622's rebase, so where a line can move each step also

### What may be deleted

**Exactly one thing:** a file `~/.local/bin/<name>` that is a regular file, not a link,
at most 1024 bytes, and `cmp`-identical to one of these five templates, rendered with
the package from its own `mise use` line and `<name>` from its own file name.

```
quiet            #!/bin/bash\nexport MISE_MINIMUM_RELEASE_AGE=0\nmise use -g --quiet "P" || exit 1\nexec mise x "P" -- "B" "$@"\n
cooldown-export  #!/bin/bash\nexport MISE_MINIMUM_RELEASE_AGE=0\nmise use -g "P" || exit 1\nexec mise x "P" -- "B" "$@"\n
bail-on-failure  #!/bin/bash\nmise use -g "P" || exit 1\nexec mise x "P" -- "B" "$@"\n
mise-exec        #!/bin/bash\nmise use -g "P"\nexec mise exec "P" -- "B" "$@"\n
bare-exec        #!/bin/bash\nmise use -g "P"\nexec "B" "$@"\n
```

These are upstream's forms in `migrations/1791382872.sh:legacy_wrapper_template`.

**`~/.local/share/mise`, `~/.config/mise`, shims and wrappers are never touched**, and
nothing in this plan writes under them. Nor is any launcher that differs by one byte,
any link, or any script a person wrote.

Two upstream deletions already exist and do not change: `omarchy-install-hermes-cli
--now` and Remove > Preinstalls each remove Omarchy's marked Hermes wrapper, when a
person asks. Neither runs at activation.

### 5. Launchers, the notice, the hook (codex)

**`pkgs/omarchy/nix-bin/omarchy-mise-unshadow`, whole file:**

```bash
#!/usr/bin/env bash

# nixarchy:new
# omarchy:summary=Remove upstream's generated mise launchers and record what mise left
# omarchy:args=[--notify]
# omarchy:hidden=true

# Removes a ~/.local/bin file only when it is upstream's generated launcher, byte for
# byte: mise is gone, so it can only fail, and it satisfies `command -v` and blocks its
# own replacement. ~/.local/share/mise, ~/.config/mise and anything else stay.
set -euo pipefail

bin="$HOME/.local/bin"
state="$HOME/.local/state/nixarchy"
notice="$state/mise-notice"

if [[ ${1:-} == --notify ]]; then
  [[ -e $notice && ! -e $notice.shown ]] || exit 0
  # Marked only on success: the daemon may not be up yet, and the next login retries.
  if omarchy-notification-send -u normal "mise is no longer part of nixarchy" "$(<"$notice")"; then
    touch "$notice.shown"
  fi
  exit 0
fi

template() {
  case $1 in
    quiet) printf '#!/bin/bash\nexport MISE_MINIMUM_RELEASE_AGE=0\nmise use -g --quiet "%s" || exit 1\nexec mise x "%s" -- "%s" "$@"\n' "$2" "$2" "$3" ;;
    cooldown-export) printf '#!/bin/bash\nexport MISE_MINIMUM_RELEASE_AGE=0\nmise use -g "%s" || exit 1\nexec mise x "%s" -- "%s" "$@"\n' "$2" "$2" "$3" ;;
    bail-on-failure) printf '#!/bin/bash\nmise use -g "%s" || exit 1\nexec mise x "%s" -- "%s" "$@"\n' "$2" "$2" "$3" ;;
    mise-exec) printf '#!/bin/bash\nmise use -g "%s"\nexec mise exec "%s" -- "%s" "$@"\n' "$2" "$2" "$3" ;;
    bare-exec) printf '#!/bin/bash\nmise use -g "%s"\nexec "%s" "$@"\n' "$2" "$3" ;;
  esac
}

is_generated() {
  local f=$1 line package= form
  [[ -f $f && ! -L $f ]] || return 1
  (($(stat -c%s -- "$f") <= 1024)) || return 1
  while IFS= read -r line; do
    if [[ $line =~ ^mise\ use\ -g(\ --quiet)?\ \"([^\"]+)\" ]]; then
      package=${BASH_REMATCH[2]}
      break
    fi
  done <"$f"
  [[ -n $package ]] || return 1
  for form in quiet cooldown-export bail-on-failure mise-exec bare-exec; do
    if cmp -s -- "$f" <(template "$form" "$package" "${f##*/}"); then
      return 0
    fi
  done
  return 1
}

removed=()
left=()
for f in "$bin"/*; do
  [[ -f $f && ! -L $f ]] || continue
  if is_generated "$f"; then
    rm -f -- "$f"
    echo "omarchy-mise-unshadow: removed $f"
    removed+=("$f")
  elif grep -qaE '(^|[^[:alnum:]_-])mise([[:space:]]|$)' -- "$f"; then
    left+=("$f")
  fi
done

tools=()
for d in "$HOME/.local/share/mise/installs"/*; do
  if [[ -e $d ]]; then
    tools+=("${d##*/}")
  fi
done

((${#removed[@]} + ${#left[@]} + ${#tools[@]})) || exit 0
mkdir -p "$state"

# Written once, as the record, and only ever added to. Rewriting it every activation
# would lose the list of what was removed, and showing it again would be noise.
if [[ ! -e $notice ]]; then
  {
    echo "mise is no longer part of nixarchy. Nothing you own was deleted except any launchers listed here."
    if ((${#tools[@]})); then
      echo "Off your PATH now, in ~/.local/share/mise/installs: ${tools[*]}"
    fi
    if ((${#left[@]})); then
      echo "Left in place, because they are not exactly what Omarchy generated: ${left[*]}"
    fi
    echo "To move: omarchy default agent <agent>, Install > Development, or nixarchy dev init."
    echo "To clean up, if you want to: rm -rf ~/.local/share/mise ~/.config/mise"
    if ((${#removed[@]})); then
      printf 'Removed launcher: %s\n' "${removed[@]}"
    fi
  } >"$notice"
  echo "nixarchy: mise is no longer part of nixarchy; see $notice"
elif ((${#removed[@]})); then
  printf 'Removed launcher: %s\n' "${removed[@]}" >>"$notice"
  rm -f -- "$notice.shown"
  echo "nixarchy: removed mise launchers; see $notice"
fi
```

## Release note and migration (section 14)

`release-notes.sh` writes no hand-written prose: section 4 of the notes comes from

> **mise is no longer part of nixarchy.** It is off the machine, off PATH, and out of

>
> Nothing you own is deleted, with one exception: launchers Omarchy generated in

> `omarchy default agent <agent>`.

> `eval "$(mise activate zsh)"` to your own rc.
> To clean up, if you want to: `rm -rf ~/.local/share/mise ~/.config/mise`.

## Rollback

Revert the squash commit. It restores the runtime `mise`, the rc activation, `/etc/mise`
and the wrappers together. A person's `~/.local/share/mise` was never touched, so their
tools come back at the next shell. Launchers already removed do not come back. A tool
someone ran through one is in mise's own config, so its shim returns; one never run is

marker, stays as harmless state. Revert `build.yml` in the same commit. #1622 stands on its own and is
not reverted.
