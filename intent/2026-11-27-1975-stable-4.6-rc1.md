# Intent: stable moves from Omarchy v4.5.0 to v4.6.0-rc1

## Problem

`main` pins Omarchy `v4.5.0`. Upstream tagged `v4.6.0-rc1`, and the
bump workflow's pull request (#1972) is a draft because its build fails:
the keybindings menu's cache tag moved from `v19` to `v22`, and the
`--replace-fail` for it no longer matches. That is only the first
failure. rc1 is 1,100 upstream commits after `v4.5.0`.

Edge has carried almost all of them already. rc1 (`745271c`) is quattro
`155c4b4`, edge's current pin, plus 33 commits. Those 33 add new `bin/`
commands, a new `/etc` file
(`systemd/logind.conf.d/30-lid-external-power.conf`), a udev rule, and
menu and package-list changes that nothing here has classified.

People who follow `main` stay on a release two minors behind edge until
this lands, and #1962's nightly review reports it every night.

## Proposed outcome

- `main` pins `github:basecamp/omarchy/v4.6.0-rc1` and every `main`
  check passes on it: `build`, `install check`, and the cheap tier.
- `main` holds edge's history through a real merge, so edge's next
  merge of `main` is clean.
- Every file the 33 commits add is classified wherever a ledger requires
  it, each with its reason.
- #1972 is closed as superseded.

## Affected users and systems

- Everyone following `main` or the RC channel gets 4.6.0-rc1 at their
  next update. `release` is untouched.
- p620's runners run the PR's `install check` and VM jobs.
- `omarchy-edge`'s next run merges the result.

## Constraints

- The #1405/#1477 sequence: merge `main`, merge `edge` for real, pin the
  tag. A merge commit, never a squash (§8); the PR merges with
  `gh pr merge --merge`.
- Pin the tag, never a sha (#1403).
- Do not push to `update/omarchy-v4.6.0-rc1`; the bump workflow owns it.
- No workflow edit. If one turns out to be needed, stop: §11.
- Local checks by tier before pushing (§6), with no package build while
  an install or edge `verify` job runs.

## Open questions

None. The owner pre-approved the intent, spec and plan for this batch
(2026-11-27). Route (a), as #1477 decided, unless the trial shows edge
must move first.
