## What this plan changes from the spec's text

The dead-key measurement was redone at this branch's pin: kbd 2.9.0, libxkbcommon 1.13.2, libx11 1.8.14, obtained with
`nix build --inputs-from . nixpkgs#…`. The literal differences match the spec's table. Five things did not survive it.
None changes an approved decision, but 2 and 3 change who is refused, so **read these before approving.**

1. **48 keys, not 47.** The spec's `< >` and `Í í` rows exist only on key 86, the ISO key beside Shift. Its
   table was measured with key 86 and its prose says 47. The check uses 48.
2. **Estonian differs too, and the spec's dismissal is wrong.** The map says `dead_caron`, the compiled table holds
   `dead_circumflex`, and that table is what the kernel runs. So `^` then `e` gives `ê` on the console and `ě` under
   XKB. The plan lists Estonian's 10 composed characters in column 4 rather than giving it `dead`, which would refuse
   `õ ä ö ü š ž` too. **Alternative: `dead`, matching Czech and Latvian.**
3. **Same dead key, different result, is now measured, and the spec called it unmeasured.** Compared with libX11's
   `en_US.UTF-8/Compose`: `us-acentos` gains `Ç ç`, and German gains `¦ ¨ ´ ¸ Ç Ð Ñ × ç ð ñ`. German's `ä ö ü ß` are
   unaffected. These go in column 4, whose definition already covers them.
4. **The `dead` token's rule.** Spec: "compared as symbols". That flags Estonian by name while saying nothing about the
   result, so the check compares composed results instead. `dead` stays on Czech and Latvian as approved, and
   Latvian also lists `'`, because its key has no dead key under XKB.
5. **`keyboard-own-options`' break.** The spec says a plain `options` "conflicts". `xkb.options` is `types.commas`, which
   joins, so nothing conflicts. The fixture asserts the **exact** `keymap_options` value, which still fails.

  at all, as a free-space install does today. The decision stands; proving that is its own issue if wanted.

```bash
# layout[:variant], split for the template.
set_keyboard() {
  xkb_layout=${1%%:*}
  case $1 in
    *:*) xkb_variant=${1#*:} ;;
    *) xkb_variant="" ;;
  esac
}

# The XKB name of a console keymap from an answers file, or nothing. Not for the
# menu: Finnish and Swedish share `fi`, so a lookup by console name finds Finnish.
xkb_for_keymap() {
  local label cmap spec rest l v
  # The caller's `||` clears set -e here, so a failed redirect would read as "no match".
  [ -r "$UI_KEYMAPS" ] && [ -r "$KBD_MODEL_MAP" ] || return 1
  while IFS=$'\t' read -r label cmap spec rest; do
    if [ "$cmap" = "$1" ]; then
      printf '%s' "$spec"
      return 0
    fi
  done <"$UI_KEYMAPS"
  while read -r cmap l _ v _; do
    [ "$cmap" = "$1" ] || continue
    l=${l%%,*} v=${v%%,*}
    [ "$v" != - ] || v=""
    case " $NONLATIN " in
      *" $l "*) printf 'us,%s%s' "$l" "${v:+:,$v}" ;;
      *) printf '%s%s' "$l" "${v:+:$v}" ;;
    esac
    return 0
  done <"$KBD_MODEL_MAP"
}

ask_keymap() {
  local choice row
  while :; do
    ui_screen "Let's set up your keyboard..."
    choice=$(cut -f1 "$UI_KEYMAPS" | gum choose --height "$(ui_widget_height)" --padding "$(ui_gum_pad)" --header "Select keyboard layout") || ui_abort
    [ -n "$choice" ] || ui_abort
    row=$(grep -F "$choice"$'\t' "$UI_KEYMAPS")
    keymap=$(cut -f2 <<<"$row")
    set_keyboard "$(cut -f3 <<<"$row")"
    keymap_moved=$(cut -f4 <<<"$row")
    keymap_dead=$(cut -f5 <<<"$row")
    loadkeys "$keymap" 2>/dev/null && return 0
    # ask_identity clears the screen, so a printed line alone would not be read.
    gum confirm "Could not load $keymap. Typing with a US keyboard: if this machine uses another layout, pick a password that types the same in both. Carry on?" && return 0
  done
}
```

```bash
# The first character of $1 the login screen would read differently, or fail.
# C.UTF-8 because the columns hold multi-byte characters; byte by byte, one would match another's bytes.
password_moved_char() {
  local LC_ALL=C.UTF-8 i c
  for ((i = 0; i < ${#keymap_moved}; i++)); do
    c=${keymap_moved:i:1}
    if [[ $1 == *"$c"* ]]; then
      printf '%s' "$c"
      return 0
    fi
  done
  if [ "$keymap_dead" = dead ] && [[ $1 == *[![:ascii:]]* ]]; then
    c=${1//[[:ascii:]]/}
    printf '%s' "${c:0:1}"
    return 0
  fi
  return 1
}
```

## `tests/installer-keymaps-compare.py`

```python
#!/usr/bin/env python3
# Each menu row's column 4/5 must say exactly what differs between the console
# table (what the installer reads the password under) and the XKB layout's
# first group (what the login screen reads it under). Why: tests/AGENTS.md.
# usage: keymaps-compare.py <menu> <libxkbcommon.so> <Compose>   (loadkeys, xkbcli on PATH)
import ctypes, re, subprocess, sys

menu, xkbso, compose = sys.argv[1:4]
# The password keys: digit row, three letter rows, and the ISO key beside Shift.
KEYS = [*range(2, 14), *range(16, 28), *range(30, 42), *range(43, 54), 86]
ACCENT = {0: "`", 1: "'", 2: "^", 3: "~", 4: '"', 5: ","}
X = ctypes.CDLL(xkbso)
X.xkb_keysym_from_name.argtypes = [ctypes.c_char_p, ctypes.c_int]
X.xkb_keysym_from_name.restype = ctypes.c_uint32
X.xkb_keysym_to_utf32.argtypes = [ctypes.c_uint32]
X.xkb_keysym_to_utf32.restype = ctypes.c_uint32

COMPOSE = {}
for line in open(compose, encoding="utf8", errors="replace"):
    m = re.match(r'\s*<(dead_\w+)>\s*<(\w+)>\s*:\s*"((?:[^"\\]|\\.)*)"', line)
    if m:
        COMPOSE[(m[1], m[2])] = m[3]


def console(name):
    out = subprocess.run(["loadkeys", "--unicode", "--mktable", name],
                         capture_output=True, text=True, check=True).stdout
    table = [[int(v, 16) for v in re.findall(r"0x[0-9a-f]+",
              re.search(rf"short {n}_map\[NR_KEYS\] = \{{(.*?)\}}", out, re.S)[1])]
             for n in ("plain", "shift")]
    accents = {}
    block = re.search(r"accent_table\[MAX_DIACR\] = \{(.*?)\n\};", out, re.S)
    for d, b, r in re.findall(r"\{'(\\.|.)', '(\\.|.)', (0x[0-9a-f]+)\}", block[1] if block else ""):
        # setdefault: the kernel takes the first match, and some maps list two.
        # [-1]: an escaped '\\' or '\'' is its last character; removing backslashes empties the first.
        accents.setdefault((d[-1], b[-1]), chr(int(r, 16)))
    return table, accents


def typed(code):
    kind = code >> 8
    if kind in (0xf0, 0xfb):
        return chr(code & 0xff) if (code & 0xff) >= 0x20 and code & 0xff != 0x7f else None
    return chr(code) if 0x20 <= code < 0xf000 else None


def xkb(spec):
    layout, _, variant = spec.split(",")[0].partition(":")
    out = subprocess.run(["xkbcli", "compile-keymap", "--layout", layout]
                         + (["--variant", variant] if variant else []),
                         capture_output=True, text=True, check=True).stdout
    codes = {a: int(b) for a, b in re.findall(r"<([A-Za-z0-9+_-]+)>\s*=\s*(\d+);", out)}
    syms = {}
    for name, body in re.findall(r"key <([A-Za-z0-9+_-]+)>\s*\{(.*?)\};", out, re.S):
        m = re.search(r"symbols\[1\]\s*=\s*\[([^\]]*)\]", body) or re.search(r"\[\s*([^\]]*)\]", body)
        if m and name in codes:
            syms[codes[name] - 8] = [s.strip() for s in m[1].split(",")]
    return syms


def char(sym):
    if sym is None or sym.startswith("dead_"):
        return None
    u = X.xkb_keysym_to_utf32(X.xkb_keysym_from_name(sym.encode(), 0))
    return chr(u) if u >= 0x20 else None


def level(syms, code, i):
    s = syms.get(code, [])
    return s[i] if i < len(s) else (s[0] if s else None)


def differs(console_map, spec):
    (table, accents), syms = console(console_map), xkb(spec)
    out = set()
    for code in KEYS:
        for i in (0, 1):
            value, sym = table[i][code], level(syms, code, i)
            ch = typed(value)
            if ch is not None and ch != char(sym):
                out.add(ch)
            if value >> 8 != 0xf4:
                continue
            accent = ACCENT.get(value & 0xff)
            if not (sym or "").startswith("dead_"):
                out.add(accent)  # no dead key there, so the accent itself moved
            for base in KEYS:
                for j in (0, 1):
                    b, bsym = typed(table[j][base]), level(syms, base, j)
                    done = accents.get((accent, b)) if b and b.isalpha() else None
                    if done and done != COMPOSE.get((sym, bsym)):
                        out.add(done)
    return out


failed = count = 0
for line in open(menu, encoding="utf8"):
    f = line.rstrip("\n").split("\t") + ["", ""]
    label, cmap, spec, chars, token = f[:5]
    count += 1
    want = differs(cmap, spec)
    if token == "dead":
        if all(c.isascii() for c in want):
            print(f"FAILED: {label}: dead token, and nothing non-ASCII differs"); failed += 1
        want = {c for c in want if c.isascii()}
    elif token:
        print(f"FAILED: {label}: unknown token {token}"); failed += 1
    have = set(chars)
    if have != want:
        print(f"FAILED: {label} ({cmap} -> {spec}): column 4 lacks {sorted(want - have)}, "
              f"and lists {sorted(have - want)} which do not differ"); failed += 1
if count == 0 or failed:
    sys.exit(1)
print(f"OK: {count} rows say exactly what differs")
```
