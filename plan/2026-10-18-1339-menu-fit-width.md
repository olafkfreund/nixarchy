# Plan: the Omarchy menu is wide enough to show its labels

## Decisions carried from the approved spec

- **One carried `--replace-fail` substitution** on upstream's single
  `cardWidth` line in `shell/plugins/menu/Menu.qml` (Omarchy v4.0.5, line 112).
  It is applied after the #1301 patch and the #1305 substitutions on the same
  file. The replacement text lives in `pkgs/omarchy/1339-menu-fit-width.qml`,
  not inline, so `nix fmt` does not re-flow `installPhase`.
- **Behaviour:** `cardWidth = min(max(fitWidth, <upstream expression,
  verbatim>), Style.space(640), panel.width - Style.gapsOut * 2)`.
  - `fitWidth` is computed in `onLayoutSerialChanged`: the widest
    `displayModel` label, measured by a `TextMetrics` with the row label's font
    (`root.fontFamily`, `Style.font.heading`, `Font.Medium`), plus fixed row
    chrome.
  - It is reset on `activeMenu` and `dmenuActive` changes only, so it grows
    while a menu is open and never shrinks on a filter.
- **Cap:** a fixed `Style.space(640)`. **Upstream:** not filed; CARRIED.
- **No new option.**
- **Docs:** a `pkgs/AGENTS.md` entry with an anchor, linked from a `# Why:`
  line.
- **Verification:** extend the existing headless `checks.menu-keys`; do not add
  a new check.

## Steps

1. **New file `pkgs/omarchy/1339-menu-fit-width.qml`.** It holds exactly this
   text: two-space indent, no trailing newline issue, because `$(cat)` strips
   it.

   ```qml
     property int cardWidth: Math.min(Math.max(root.fitWidth, root.dmenuActive ? Style.space(root.dmenuWidth) : ((root.activeMenu === "trigger.capture.screenrecord" || root.activeMenu === "style.font") ? Style.space(520) : Style.space(300))), Style.space(640), panel.width - Style.gapsOut * 2)
     // Width that fits the widest label of the open menu (#1339). It only grows
     // while the menu is open, so filtering does not make the card jump.
     property int fitWidth: 0
     onActiveMenuChanged: fitWidth = 0
     onDmenuActiveChanged: fitWidth = 0
     onLayoutSerialChanged: {
       var widest = 0
       for (var i = 0; i < displayModel.count; i++) {
         labelMetrics.text = displayModel.get(i).label || ""
         widest = Math.max(widest, labelMetrics.advanceWidth)
       }
       var chrome = root.rowReservedBorderLeft + Style.space(8 + 36 + 6 + 6 + 14 + 12) + card.contentLeftInset + card.contentRightInset
       fitWidth = Math.max(fitWidth, Math.ceil(widest + chrome))
     }
     TextMetrics {
       id: labelMetrics
       font.family: root.fontFamily
       font.pixelSize: Style.font.heading
       font.weight: Font.Medium
     }
   ```

   → verify by `git add` (see Traps), then step 2's build.
   Traps: **a flake in a worktree sees only tracked or staged files**. Without
   `git add`, the build reports `path … does not exist`.
