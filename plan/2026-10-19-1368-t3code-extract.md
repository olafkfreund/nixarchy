# Plan: T3 Code installs on nixarchy

Approved decisions, carried from the spec:

- On nixarchy an AppImage runs through `appimage-run` (binfmt), which passes
  `--appimage-extract` on to the app. Confirmed on an edge machine: the
  installer's call launched T3 Code, and `appimage-run -x squashfs-root`
  extracted `t3code.desktop` and all nine icons.
- **The fix lives on `main`**, in `pkgs/omarchy/default.nix`, guarded by
  `[ -e …/omarchy-install-t3code-app ]`: inert on stable, active on edge
  through its merge of `main`.
- The two `--appimage-extract` lines (quattro 81fd2d2, lines 83-84, inside
  `( cd "$work" … )`) become one `appimage-run -x squashfs-root "$download"`,
  preceded by a check that exits 1 with "Installing T3 Code needs AppImage
  support: programs.appimage.enable = true;" when `appimage-run` is missing.
  Both anchors use `--replace-fail`.
- A new `checks.appimage-extract` fails, naming file:line, on any non-comment
  `--appimage-extract` in `${omarchy}/share/omarchy/bin`.
- Three files, so the `coder` agent implements steps 1-3 and the lead does
  step 4.

## Steps

1. **`pkgs/omarchy/default.nix`, beside the other bin substitutions**
   (after the `omarchy-menu-keybindings` block near line 451), add:

   ```sh
   # CARRIED (#1368): an AppImage here runs through appimage-run (binfmt), which
   # passes --appimage-extract to the app instead of extracting. Quattro only.
   if [ -e $out/share/omarchy/bin/omarchy-install-t3code-app ]; then
     substituteInPlace $out/share/omarchy/bin/omarchy-install-t3code-app \
       --replace-fail '  "$download" --appimage-extract t3code.desktop >/dev/null' \
                      '  { command -v appimage-run >/dev/null || { echo "Installing T3 Code needs AppImage support: programs.appimage.enable = true;" >&2; exit 1; }; } && appimage-run -x squashfs-root "$download" >/dev/null' \
       --replace-fail "  \"\$download\" --appimage-extract 'usr/share/icons/hicolor/*/apps/t3code.png' >/dev/null" ""
   fi
   ```

   **One line, deliberately.** The spec showed the replacement on two lines.
   A newline inside this `''…''` Nix string changes the string's common
   indentation (CLAUDE.md §5's reindent trap), so the two commands are
   joined with `&&` instead. Same behaviour; recorded as a deviation.
   → verify: `nix fmt`, then `git diff --stat` (one file, a few lines).
   Traps: inside the Nix `''…''` string, `$out` and `"$download"` need no
   escaping, and no `''` and no `${` may appear in the added text.

2. **`tests/appimage-extract.nix`, the new check:**

   ```nix
   { pkgs, omarchy }:
   # #1368: an AppImage here runs through appimage-run (binfmt), which passes
   # --appimage-extract on to the app, so a script that self-extracts one launches it.
   pkgs.runCommand "nixarchy-appimage-extract" { } ''
     hits=$(grep -rn -- '--appimage-extract' ${omarchy}/share/omarchy/bin | grep -vE ':[0-9]+:[[:space:]]*#' || true)
     if [ -n "$hits" ]; then
       echo "these scripts self-extract an AppImage, which appimage-run passes to the app (#1368):" >&2
       echo "$hits" >&2
       exit 1
     fi
     touch "$out"
   ''
   ```

   Neither grep reads with `-q`, so `pipefail` cannot cause SIGPIPE (#1352).
   → verify: `nix fmt`.

3. **`flake.nix`:** register it beside `panel-loaders` (line 2469):
   `appimage-extract = import ./tests/appimage-extract.nix { pkgs = pkgsFor.${system}; omarchy = self.packages.${system}.omarchy; };`
   with a one-line comment.
   → verify: `git add -A`, then
   `nix eval --raw .#checks.x86_64-linux.appimage-extract.drvPath`.

4. **Lead: prove and ship.** Builds go under the lock; `.#omarchy` is
   package tier (no p620 system build, load below 12).
   - `main`: build `.#omarchy` and `checks.appimage-extract`, both green.
   - **Red (§1):** run the check's two lines in a bash script against the
     already-built `/nix/store/2spx9zyk3jvv4j24fw00bh2k40b22dlq-omarchy-edge-20261019-81fd2d2`
     (unpatched quattro). It must exit 1, naming
     `omarchy-install-t3code-app:83` and `:84`.
   - **Edge green:** a scratch `git worktree add --detach` of
     `origin/edge-candidate`, merge this branch into it (it must be
     conflict-free), and build `.#omarchy` there. Its
     `omarchy-install-t3code-app` contains `appimage-run -x squashfs-root`,
     `checks.appimage-extract` is green, and `bash -n` on the patched script
     passes. Remove the scratch tree.
   - Commit "T3 Code installs on nixarchy: its installer extracts the AppImage

   - After edge publishes: on razer, Install › T3 Code installs, and the
