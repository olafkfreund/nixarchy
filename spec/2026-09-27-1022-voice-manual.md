# Spec: Voice's manual entry says what Voice is, with the media to show it

The intent was approved without answers, so its three recommendations stand:
the size is re-measured at the new pin, the pin is bumped here, and the GIF is
the plugin's menu Run.

## Design

### 1. The pin

- `flake.nix:227` changes its URL from
  `github:olafkfreund/nixarchy-voice/647f9e5…` to the full commit of `7c51dfb`,
  upstream `main` with #158, #161, #162, #164 and #165.
- `flake.lock`: `nix flake update nixarchy-voice` records it.
- Both `follows` stay (`nixpkgs`, `ai-mirror`).
- The comment above the input is corrected:
  - `services.omarchy-voice.enable` becomes `programs.nixarchy.voice.enable`
    here, or `programs.omarchy-voice` upstream;
  - "about a gigabyte" becomes the measured figure (section 2).

### 2. The size: measured, once, used everywhere

- **Method:** #774's own. `nix path-info -Sh` on the voice package, built with
  this flake's `nixpkgs` (the input follows it), at **both** pins.
- **Why both:** the old pin has to reproduce 6.7 GiB, or the method is not the
  one #774 used and the new number means nothing.
- The new pin's number, rounded to one decimal GiB, replaces every figure:
  - `plugins.md:396` and `:403`;
  - the `flake.nix` comment;
  - `data/apps.nix:361,385`;
  - `modules/nixos.nix:269,272`.
- `plugins.md:396`'s "~150 MB whisper model … separate from the 6.7 GiB here"
  is rewritten as one statement of one number.

### 3. The Voice section (`docs/manual/plugins.md:388-408`)

Rewritten in the section's existing four-part shape.

- **Heading line:** the repo and the plugin's page, kept.
- **What it solves:** unchanged in substance. Voice is speech into actions,
  and dictation (Voxtype, F9) stays for typing.
- **What it does:**
  - the wake word or key, whisper.cpp on the CPU, the signed-in model, a local
    voice (as now);
  - **plus actions**: named recipes you say, pick in **Voice ▸ Actions**, or
    run from the CLI, and make by asking ("make that an action called …");
  - **routines**: actions on a schedule, run as systemd user timers, with the
    result as a notification;
  - commands run in Oma's own terminal session, and a failure is reported as
    one.
- **Why it's opt-in:**
  - the model account, and what it sends (as now);
  - the measured size;
  - the approve-once rule: a confirmation step can be approved once, deny
    rules never.
- **Turning it on:** "Find **Voice** in **Install ▸ Search** and apply, or set
  `programs.nixarchy.voice.enable = true`." The false **Set up voice** row and
  the backend question go.
- **Media:** replace the "*Not recorded yet*" line with:
  - the GIF (`../img/features/voice.gif`);
  - the still (`../img/plugins/voice-actions.webp`);
  - one sentence linking the recording with sound on the plugin's page.

### 5. Media

Both files come from the plugin's take-6 recording on razer: the default Tokyo
Night theme, the Winding Road wallpaper, and nothing private in frame (reviewed
frame by frame, in nixarchy-voice#163's plan).

- **`docs/img/features/voice.gif`:** the plugin's GIF as is. It shows the
  Voice ▸ Actions ▸ Run of a saved action, ending on `git status` in Oma's own
  terminal:
  - 900x563, 4 fps, lanczos, a 96-colour palette, 0.94 MB;
  - made with `encode-gif.sh`'s settings from a 16:10 centre crop.
- **`docs/img/plugins/voice-actions.webp`:** the Voice ▸ Actions menu open,
  from the recording's still:
  - a 16:10 centre crop (1728x1080) of the full 1920x1080 frame, scaled to
    1280x800, as webp;
  - this is a *real* whole-desktop capture in the default look, with the menu
    where it really opens (centred), so nothing is cut out and composed;
  - `docs/AGENTS.md`'s composition exists for panels photographed on their
    own, which this is not.

## Alternatives rejected

- **Keeping 6.7 GiB without re-measuring:** the package changed three times
  since it was measured, and the number is quoted in five places.
- **Docs only, leaving the pin to the nightly bump:** the section would
  describe actions and routines that the pinned `647f9e5` does not have.
- **A GIF of an action being made by asking:** its key moment is Oma reading
  the recipe back aloud, and a silent GIF shows an empty desktop for
  28 seconds. The page's video carries that part.
- **Composing the menu panel onto `00-desktop.jpg`:** it would mean cutting a
  panel out of a frame that already *is* the default desktop, to paste it back
  onto a photo of the same desktop.
- **Adding a "Set up voice" menu row so the manual becomes true:** that is a
  feature, and `data/apps.nix` records why there is no `install.ai` submenu.
  The manual follows the code.

## Risks

- **The pin bump changes Voice for anyone who has it on.** No machine in this
  repo does (`voiceIsNotADefault`), and upstream's own suites passed on each
  of those merges. `checks.options` and the flake checks run here too.
- **The size may change a lot.** The new number is used as measured. If it
  differs from 6.7 GiB by more than about 10%, the PR says why (for example,
  a model change upstream).
- **Media in the repo:** about 1.1 MB (0.94 MB GIF plus a webp still).
- **Another agent in the same files:** `docs/manual/plugins.md` is shared by
  every plugin. Rebase on `main` just before the PR, and check the bus for
  work in `plugins.md`.
