  - `nix flake update omarchy`, which locks `237f1b4`, and no other lock

## Steps

1. **`flake.nix` and `flake.lock`, the bump.**
   - Edit both lines with `sed`, as the bump job does:
     `s|github:basecamp/omarchy/v4.0.5|github:basecamp/omarchy/v4.0.6|` and
     `s|omarchyVersion = "4.0.5"|omarchyVersion = "4.0.6"|`.
   - Run `nix flake update omarchy`.
   - Verify with `git diff --stat`: two lines in `flake.nix`, and only the
     `omarchy` node in `flake.lock`.
   - **§1 red:** `git add -A`, then build `.#omarchy`. It must fail with
     `Hunk #1 FAILED at 29`. Capture that output for the PR.
   - Commit this as the first commit, with a temporary subject (§8 squashes
     it).

2. **The 1153 patch, the rebase.**
   - Replace hunk 1's context with 4.0.6's lines 29-49, and fix the header
     to `-29,21 +29,32`.
   - Verify with `git diff`: only context lines and the header change, and
     there are no `+`/`-` line changes inside the hunk. Then dry-run against
     the 4.0.6 source:
     `patch -p1 --dry-run --forward --fuzz=0` in a clone of `v4.0.6`
     (`/mnt/data/vmtest/omarchy-406`).
   - Traps:
     - a wrong hunk count makes `patch` silently drop the following hunks,
       which happened once while writing the spec ("1 out of 1 hunk");
     - the dry-run must list hunks 2-10 for `lock/Service.qml`.

3. **Lead: prove and ship.**
   - **Green**, at the package tier (no p620 system build running, load
     below 12):
     - `.#omarchy` builds;
     - `nix eval --raw .#omarchy.version` prints `4.0.6`.
   - **Cheap checks**, under `flock /mnt/data/vmtest/codex-build.lock`:
     `bin-ledger`, `omarchy-version-label`, `restart-terminal-wrapped`,
     `appimage-extract`, plus `nix fmt -- --ci`.
   - **Edge trial:** a `git worktree add --detach` of `origin/edge-candidate`,
     merged with this branch. Resolve as above, and
     `git diff --cached HEAD` must be empty.
   - Squash to one commit, with the subject "Omarchy 4.0.6: the
     lock-screen patch is re-anchored on upstream's new currentlyLocked()".
   - Open the PR with `Closes #1374`, linking intent, spec and plan, and
     including the red output.
   - Set auto-merge, and check `gh pr view --json mergeable`.

4. **After merge:**
   - merge `main` into `edge-candidate` as in the edge trial, push, and run
     `omarchy-edge.yml -f from_candidate=true`;
   - the owner tags v4.0.6-1, and I add the notes above to the release.
