# Plan: Setup > Remote desktop offers gliff

The approved decisions:

- **One new row**, `setup.remote.gliff`, labelled "Connect with gliff". It is
  appended to `remoteMenuRows`.
- **Its action** is `uwsm-app -- gliff`: gliff's own window, with no terminal
  and no host prompt.
- **Its `when`** is `command -v gliff >/dev/null`, so a machine that removed
  gliff never sees a row that names it.
- **Its icon is 󰐲**, reused from the connect row because it is proven to
  render.
- **The two RDP rows stay unchanged.** No sshd change, no `nixarchy-remote`
  change.
- **The check** lives in `checks.remote-tunnel`. One sentence goes in the
  manual.

It touches three files or more, so the `coder` agent implements the steps, per the
managed model split; this session runs the §6-gated builds if the coder's guard
blocks them (as on #1226), reviews with a fresh Opus agent, and commits.
