# Intent: machines seeded before Omarchy 4.5 get the 4.5 user-file migrations that still apply

One intent for #1673, #1674, #1675, #1676, #1677, #1678, #1679, #1680 and
#1681: nine follow-ups from #1610 (PR #1670) covering 18 migration rows, one
PR with one commit per issue.

## Problem

nixarchy does not run Omarchy's migrations, and the seed copies
`share/omarchy/config` into `~/.config` without overwriting anything
(`modules/home.nix:1150,1196`). A home seeded on 4.0.x therefore keeps 4.0's
files after a 4.5 bump. #1670 ported the three bar migrations. The other 18
rows in scope here, and two more, are `declined` in
`data/user-migrations.nix` with the placeholder "needs its own fixture first
(#1610 follow-up)": a decision nobody has made yet. The two not in scope
are `1788129995` (#1671, imv's Ctrl+E) and `1791723398` (#1672, Neovim
transparency), whose titles are not "Pre-4.5 machines miss..." (open
question 5).

The seed already carries several 4.5 fixes (OverlayScrollbar in
`chromium-flags.conf:4`, herdr's `panel_bg`, fcitx5's `0=Shift_L`, the
`looknfeel.lua` example). That covers **new homes only**, so it is not a
reason to decline for pre-4.5 homes.

One row hides a live bug rather than a stale file. `omarchy-agent` in 4.5
has no `gemini` case and exits with "Unsupported default agent"
(`bin/omarchy-agent:201-203`). But `programs.nixarchy.defaultAgent` still
accepts `gemini` (`modules/nixos.nix:667`), maps it to `gemini-cli`
(`pkgs/omarchy/nix-bin/omarchy-default-agent:25,76`), and rewrites
`defaults/agent` at every activation (`home.nix:1522-1539`). Setting that
option breaks the agent launcher on any machine, new or old (#1681).

## Proposed outcome

Every one of the 18 rows in scope ends `ported`, `partial` or `declined`, with a
reason that is a decision rather than a placeholder. The ported ones run for
a pre-4.5 home and leave a 4.5 home untouched.

## Affected users and systems

- Every home seeded on 4.0.x: the owner's machines and any early user.
- `pkgs/omarchy/nix-bin/omarchy-migrate-user`, `data/user-migrations.nix`,
  `tests/user-migrations*`, and for #1681 `modules/nixos.nix` and
  `omarchy-default-agent`.

## Constraints

- `omarchy-migrate-user` exits early unless `.bar.centerAnchor` exists
  (line 21) and when the three bar markers exist (line 22). Neither gate
  fits the new rows, so each migration needs its own condition. That
  restructure is the first commit, before any port.
- The script is IPC-only because the running shell owns `shell.json` (#847).
  None of these files is owned that way, so direct edits are allowed, but
  each must skip a symlink (a home-manager link is the user's, §1 "a content
  test is not an ownership test", #1304) and a file the user customised.
- Upstream's markers (`$OMARCHY_MIGRATION_STATE/<id>.sh`) are written only
  after the result is re-read, as #1670 does.
- Every port is compared with upstream's own script on the same fixture.
  `tests/user-migrations/run` compares only `shell.json` today, and
  `run_oracle` hard-codes the bar ids (lines 40-51). These ports delete
  files, repoint links and edit Lua and TOML, so the harness must compare
  the whole fixture tree, and stub upstream's session commands (`hyprctl
  reload`, herdr restart, `omarchy-theme-refresh`) rather than run them. §1: each port's fixture is proven to fail with the
  port removed.
- Never run `mise`. #1681's upstream script installs `agy` through mise;
  that half is not ported. nixarchy installs agents from nixpkgs.
- **Two declines now** (1791123731, a comment; 1792474908, Brave Origin is
  unavailable). Rewriting a user's file must be justified by a visible
  break; a comment is not one.
- One PR, one commit per issue, merged with a merge commit, stacked on
  #1670 until it merges.

## Decisions (owner, 2026-11-08)

1. **#1681:** `agy` joins the `defaultAgent` enum. `gemini` keeps evaluating, maps to `agy`, and warns.
2. **Deletions** are ported as upstream does them: 4.0's notification history holds old message text, and the saved negative-id layouts are what broke workspace 1.
3. The two declines stand (1791123731, 1792474908).
4. **#1677 / 1793477875** is ported, and it skips any key the user has already bound.
5. **#1671 and #1672 join the batch**, so it covers every remaining placeholder row: 20 rows, eleven issues, one commit per issue.

## Open questions (as drafted)

1. **#1681:** removing `gemini` from the `defaultAgent` enum would make an
   existing `defaultAgent = "gemini"` fail evaluation, and `agy` is not in
   the enum today (only `omarchy-default-agent:72-76` knows it). Options:
   (a) add `agy` to the enum and keep `gemini` evaluating, mapped to `agy`
   with a warning; (b) keep `gemini` as a real choice, by teaching the
   launcher its case back. Either way the launcher must not reject a value
   the option accepts. (a) is the recommendation, since 4.5 dropped Gemini.
2. **Deletions:** #1680 deletes 4.0's notification history, which holds
   old message text, and #1673's `1787679775` deletes saved named-workspace
   layouts. Port both as upstream does, or move the files aside?
3. The two declines (1791123731, 1792474908): agree?
4. **#1677 / 1793477875** appends F9 and Super+Ctrl+X to the user's own
   `bindings.lua`, and either key may already be bound to something else.
   Port it (skipping a key already bound), or decline and say in the
   release notes that dictation moved to Alt+Space?
5. Include #1671 and #1672 in this PR? They are the same kind of follow-up
   and would make the batch every remaining placeholder row.
