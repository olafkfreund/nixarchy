# Plan: Validate installer inputs before installation

Implement only after #1089 merges. Fetch and rebase `fix/1113-installer-input-validation` onto current `origin/main` first, read the rebase status, and recheck the function references below. #1089 changes disk safety in the same `installer/install.sh`; preserve all of it. No workflow edit or local VM run is authorized by this plan.

Approved behavior: use the existing shared name validators for wizard, answers, and `--host`; preserve ASCII name syntax while enforcing 31-byte usernames and 63-byte hostnames. Generate the reserved-name list at build time from the `.name` value of each non-normal user in `self.nixosConfigurations.reference.config.users.users`, plus the missing `daemon` name; preserve the normal `omarchy` username and the existing `nixbld*` refusal. Splice that list into top-level `RESERVED_USERS=@reservedusers@` beside `TZDIR` and `KEYMAPS`; the validator reads the variable, so raw-function tests can set it. Do not use the live ISO's `/etc/passwd` or maintain a handwritten system-account list. Reject an answers-file timezone unless it is a relative, non-traversing path to a regular `TZif` file under `TZDIR`; `zone.tab` and directories fail. Match an answers-file keymap as a literal basename of an existing `.map.gz` file under `KEYMAPS`, never as a `find` pattern or with `producer | grep -q`. Put these checks in small `validate_timezone` and `validate_keymap` functions. Refuse invalid answers with the existing specific error and exit 2, without a fallback. Put nmcli parsing in its own small function: request `nmcli -t -e no -f SIGNAL,SECURITY,SSID`, split only on the first two colons, and pass the remainder as the literal SSID to `nmcli device wifi connect`; preserve deduplication, signal sort, and security display. A failed write of `nixarchy-hardware.nix` stops `generate_hardware_config` with a file-naming error; unavailable hardware detection remains best-effort.
