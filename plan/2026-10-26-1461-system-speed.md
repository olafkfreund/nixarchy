# Plan: a nixpkgs bump's system jobs finish well inside their limits

This carries the spec's three decisions:

- **A.** A same-repository `update/nixpkgs-*` pull request pushes the
  allowlist closures, minus the referrers-closure of the flake source and of
  `.#omarchy`.
- **B.** The session VM test moves to a new job, `system-session`, which joins
  the `system` aggregator's `needs:` and its result loop.
- **C.** `cache-budget.sh` builds the allowlist in one `nix build --json`,
  falling back to the per-entry loop when the batch fails.

Steps 1-3 touch only scripts and tests, so they can run before #1466 merges.
Step 4 edits `build.yml` and waits for #1466, which removes a system-checks
step and renames a system-build step.

## Steps

1. **`.github/scripts/cachix-push.sh`, closure mode** (the block after
   `# Closures come from main.`, around lines 134-138).
   - Replace the `main`-only refusal with a function `closure_context`. It
     prints `main`, `bump` or nothing:
     - `main` when `GITHUB_REF=refs/heads/main`;
     - `bump` when `GITHUB_EVENT_NAME=pull_request`, `GITHUB_HEAD_REF`
       matches `update/nixpkgs-*`, and
       `jq -r .pull_request.head.repo.full_name "$GITHUB_EVENT_PATH"` equals
       `$GITHUB_REPOSITORY`;
     - nothing otherwise, which exits 0 with the current message, naming
       the ref.
   - In `bump` mode, before the loop, compute the exclusion set once:
     ```
     src=$(nix flake metadata --json . | jq -r .path)
     tree=$(nix path-info .#omarchy)
     nix-store --query --referrers-closure "$src" "$tree" | sort -u > "$excl"
     ```
     Guard each with `|| { echo "::warning::..."; exit 0; }`: a bump that
     cannot compute the set pushes nothing rather than everything.
   - Per entry, push `comm -23 <(nix path-info -r "$attr" | sort) "$excl"`,
     and print `pushing <attr>: N paths, M left out as commit-specific`.
     Keep the zero-closure refusal and the warning-not-failure on a failed
     push.
   - Use a global for the temporary file, so an EXIT trap sees it (§5).
   - Traps: §4 (`mapfile` and process substitution: capture first); §13 (a
     field that may be empty).
2. **`tests/cache-budget.nix`.** Extend its stubs, adding `nix-store
   --query --referrers-closure` and `nix flake metadata --json` to the `nix`
   stub, plus a `$GITHUB_EVENT_PATH` fixture. Add these cases:
   - a bump PR from this repository pushes the closure minus the
     excluded paths. Exact lines sent to `cachix push`: a path that
     references the source is absent; a path that does not is present.
   - a bump-named PR from a fork pushes nothing;
   - an ordinary PR pushes nothing;
   - `main` pushes the full closure, as the existing case does.

   §1: remove the head-repository check, and the fork case goes red; skip
   the exclusion, and the bump case goes red.
3. **`.github/scripts/cache-budget.sh`.**
   - Before the per-entry loop (around line 39), build every entry in one
     `nix build --no-link --json "${entries[@]}"`, and map each entry to its
     out path in argument order. `nix build --json` keeps argument order:
     check that against two entries before relying on it.
   - The loop then reads `nix path-info -r --json <outpath>` instead of the
     attribute, so nothing re-evaluates.
   - If the batch fails, fall back to the current per-entry `nix build`
     loop, so the error names the entry.

   Verify: the report before and after is identical on the same tree. Time
   both, cold (`NIX_CONFIG="eval-cache = false"`), under the build lock.
   `tests/cache-budget.nix` stays green.
4. **`.github/workflows/build.yml`**, after #1466 merges (rebase first).
   - Move "Drive a session and the app-selection loop" out of `system-build`
     into a new job `system-session`. Copy `system-build`'s header: `needs:
     gate`, `if: ${{ !cancelled() }}`, `runs-on`, setup-nix, cachix
     (`skipPush: true`), free-disk, and the "gate did not succeed" and
     "Nothing here can affect a build" steps. Copy its `failure-digest`
     output too.
   - Give it `timeout-minutes: 45`: a cold VM toplevel build of about 25
     minutes plus the 10-minute test.
   - In the `system` aggregator, add `system-session` to `needs:`, to the
     `for r in ...` loop, and to the digest join.
   - Run actionlint. Check that `.github/scripts/copilot-handoff.sh`'s
     `name!="system"` filter is still right.
   - Traps: §4 (the hand-kept aggregator lists fail open); §11 (a workflow
     change, approved by the owner at this gate).

## Deviations recorded during implementation

- **Step 3 maps every output of an entry.** It uses `[.outputs[]]`,
  space-joined, not `.outputs.out`. A multi-output package such as jq has no
  `out`, and the batch would then fall back to the slow loop on every run,
  silently.
- **Step 3 also falls back** when the batch yields a different number of
  results than entries, or an empty one. Without that, a failed `mapfile`
  would read as an empty list (§4).
- **Step 1:** `nix-store --query --referrers-closure` on the flake source was
  run for real on this tree. It returns only the source itself until
  something built from the commit refers to it, which is the CI case. The
  bump run's log line ("N paths, M left out as commit-specific") is the first
  real measurement.
- **`cachix-push.sh`'s header and usage line** describe the bump context.
- **Review fixes (step 1):** `bump` needs `GITHUB_HEAD_REF` to match
  `update/nixpkgs-[0-9]*`, not `update/nixpkgs-blocked`; an unmerged red bump's
  pushed paths are never downloaded again and are evicted first, and the
  nightly repush heals the allowlist. `cache-budget.sh`'s header and
  AGENTS.md §6 say so.
- **`.#omarchy` is resolved by `nix eval --raw .#omarchy.outPath`**, and is a
  referrers root only if `nix path-info` finds it locally, so the apps and
  system-checks jobs push instead of skipping. An empty exclusion set is
  `skip_all` (the source is its own referrer, so empty means the query broke).
- **Main path:** a failing `nix path-info -r` is an error for that entry, with
  a non-zero exit.
- **Step 4:** `system-session` has `timeout-minutes: 75`, not 45, to match its
  siblings: a cold bump compiles its own VM closure. The aggregator and
  push-step comments are corrected.
- **`cache-budget.sh`** disables globbing (`set -f`) around the unquoted
  output expansion.
- **`tests/cache-budget.nix`:** the `nix-store` stub records its roots and
  emits `iii-refsrc` only when the source is among them. New cases: undated
  branch, tree as a root, tree absent from the store, `flake metadata`/eval/
  `nix-store` failures, an unreadable event file, and `path-info -r` failing
  on main.
