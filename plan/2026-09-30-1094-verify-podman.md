# Plan: Check running Distrobox containers only

`nixarchy-verify` currently lists every Podman container and enters each as a Distrobox, which misreports ordinary containers and starts stopped ones. Select only containers labeled `manager=distrobox` that are running; the pinned Distrobox creator writes that label. Keep the existing first-start, export, and entrypoint checks for those selected boxes. Show a concise count of stopped boxes skipped. A failed Podman listing is a verification failure, never an empty successful result. No box may be entered after discovery fails. The live hardware/network health still belongs to `pkgs/verify.sh`; a cheap stubbed check protects selection and side effects in CI. No workflow gate change is needed.
